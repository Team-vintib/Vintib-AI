# 권한 정책 초안

출처: `docs/notion/기능 정의서.md`, `docs/notion/화면 기반 개발 요구 문서.md`

## 사용자 유형

| 사용자 | 허용 범위 |
| --- | --- |
| 비회원 | 홈, 상품 목록/상세, 라이브 목록/시청, 검색 |
| 일반 회원 | 구매, 판매, 상품 등록, 라이브 개설, 채팅, 경매, AI 시착, 팔로우, 찜, 포인트 |
| 사업자 회원 | 일반 회원 기능 + 사업자 인증/세금계산서 관련 기능 |
| 운영자 | 운영 정책 수행. MVP에서 별도 운영자 화면 제외 |

## 공통 접근 제한

- 비회원은 채팅, 찜, 팔로우, 구매, 입찰, AI 시착을 사용할 수 없습니다.
- 보호 화면 진입 시 미로그인 또는 토큰 만료는 `AUTH_REQUIRED`로 처리합니다.
- 권한이 없는 사용자는 `PERMISSION_DENIED` 안내를 표시합니다.
- 본인 상품 구매/입찰/팔로우/찜 허용 여부는 미확정입니다. 확정 전에는 서버 응답 기준으로 처리합니다.

## 라우트 가드 정책 초안

| 조건 | 처리 |
| --- | --- |
| `requiresAuth`인데 미로그인 | `/auth/login` 이동 |
| `guestOnly`인데 로그인 | 홈 또는 온보딩 진행 상태로 이동 |
| 온보딩 미완료 | 다음 온보딩 단계로 이동 |
| 사업자 인증 필요 | `/business/verification` 또는 권한 안내 |
| 토큰 만료 | refresh 시도 후 실패 시 `/auth/login` 이동 |
