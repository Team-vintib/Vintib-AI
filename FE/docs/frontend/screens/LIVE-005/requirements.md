# LIVE-005 라이브 시청 화면 요구사항

## 화면 목표

라이브 방송의 영상, 상품 큐와 방송 정보를 한 화면에서 확인한다. `S15P11A108-419`는
후속 채팅·경매·AI 시착 UI가 연결될 전체 배치와 영상 영역을 구현한다.
`S15P11A108-423`은 해당 화면에 채팅 overlay와 실시간 경매 패널의 더미 UI 상태를 연결한다.
`S15P11A108-425`는 사진 중심 AI 시착 패널과 생성·결과·실패 mock 상태를 연결한다.

## 화면 구조

- 상단: 뒤로가기, LIVE 상태, 방송 제목, 시청자 수, 경과 시간, 팔로우
- 왼쪽: 현재 소개 상품을 포함한 상품 큐
- 중앙: 라이브 영상 영역과 채팅 메시지·이모지 반응·입력 overlay
- 중앙 하단: 선택 상품의 이미지와 기본 정보, 상세 이동 action
- 영상 우측 하단: AI 시착 진입 버튼
- AI 시착 진입 시 영상 오른쪽: 등록 이미지·생성·결과·실패 상태 패널
- 하단 오른쪽: 현재가·다음 입찰가·타이머·최고 입찰자·입찰 CTA가 있는 경매 패널

## S15P11A108-419 동작

- `/lives/:liveId` route로 진입한다.
- 상품 큐 항목을 선택하면 선택 상태와 하단 상품 정보가 함께 변경된다.
- 라이브 목록과 상품 상세의 기존 route에서 전달된 `liveId`를 사용한다.
- 실제 스트리밍 전에는 Figma prototype과 같은 mock poster를 표시한다.
- 화면별 mock query로 loading, error, not-found, empty-products, scheduled, ended를 확인한다.

## S15P11A108-423 동작

- Figma 더미 메시지를 영상 왼쪽 하단의 스크롤 가능한 목록으로 표시한다.
- 라이브 진행 중에는 입력한 메시지를 로컬 mock 목록에 추가할 수 있다.
- 하트·불·박수·놀람 반응 버튼은 눌림 상태와 선택 이모지가 떠오르는 로컬 효과를 제공한다.
- 경매 패널은 현재 입찰가, 다음 입찰가, 남은 시간, 최고 입찰자와 사용 가능 포인트를 표시한다.
- mock 입찰은 처리 중에 중복 클릭을 막고, 완료 후 최고 입찰자를 `나`로 바꾸며 연속 입찰을 제한한다.
- `auction` query로 `PENDING`, `LEADING`, `INSUFFICIENT_POINTS` 상태를 재현한다.
- 방송 예정·종료·취소 또는 상품 없음 상태에서는 채팅과 입찰 action을 비활성화한다.

## S15P11A108-425 동작

- 라이브 중 선택 상품이 있으면 AI 시착 버튼으로 오른쪽 패널을 연다.
- 패널에는 상품 카드를 반복하지 않고 `시착 상품 · {상품명}` 한 줄과 등록 이미지 한 장을
  크게 표시한다.
- 등록 이미지가 없으면 등록 안내, `이미지 등록`과 비활성 시작 버튼을 표시한다.
- 이미지 등록·변경은 로컬 파일 미리보기만 바꾸며 영구 저장 성공으로 표현하지 않는다.
- 시작 시 선택된 이미지를 유지한 채 생성 중 상태를 표시하고 mock 결과로 전환한다.
- `tryon=error`에서는 한 번 실패한 뒤 `다시 시도`로 결과 상태를 확인할 수 있다.
- 선택 상품이 바뀌면 이전 시착 결과와 오류를 초기화한다.
- 패널을 닫아도 라이브·채팅·경매와 진행 중인 mock 생성 상태는 유지한다.
- 선택 상품 없음, 방송 예정·종료·취소 상태에서는 AI 시착 진입을 비활성화한다.

## API와 mock 경계

`GET /api/lives/{liveId}`에서 확인된 필드만 실제 DTO 후보로 사용한다.

- 방송 ID, 호스트 ID·닉네임, 제목, 썸네일, 상태
- 예정·시작·종료 시각, 최고 시청자 수
- 편성 상품 ID·제목·정렬 순서
- 편성 상품에서 유도한 복수 카테고리 ID·이름

현재 계약에 없는 아래 값은 mock 전용 view model이다.

- 현재 동시 시청자 수
- 현재 소개 상품
- 상품 이미지, 브랜드, 가격, 소재, 상태, 실측과 하자 요약
- 영상 접속 토큰과 playback 정보
- AI 시착 등록 사진, 상품 지원 여부, 생성 job과 결과

`peakViewerCount`는 현재 동시 시청자 수로 표시하지 않는다.
`009` 확정에 따라 현재 시청자 수는 `S15P11A108-450` 전까지 표시를 생략하며, 영상 접속
토큰은 `S15P11A108-449`에서 별도 연동한다.

## 상태

- loading: 전체 layout skeleton
- error: 재시도와 라이브 목록 이동
- not-found: 존재하지 않는 방송 안내
- empty-products: 영상은 유지하고 상품 큐와 선택 상품 빈 상태 표시
- scheduled: 예정 방송 상태와 예정 시각 표시
- ended: 종료 상태와 최고 시청자 정보 표시

## 제외 범위

- 실제 영상 송출·재생 SDK
- 실제 채팅 조회·전송·WebSocket/STOMP·재접속
- 실제 경매 snapshot·입찰·입찰 내역·실시간 event
- 서버 기준 중복 클릭·선착순·연속 입찰 제한 판정
- 포인트 보류·해제와 낙찰·유찰 처리
- 실제 전신 사진 조회·영구 변경과 AI 생성·결과 저장 API
- 팔로우·찜 실제 API

## 접근성

- 상품 큐는 현재 선택과 현재 소개 상태를 텍스트와 `aria` 상태로 함께 제공한다.
- 이미지에 방송·상품을 설명하는 대체 텍스트를 제공한다.
- 상태 안내는 적절한 `status` 또는 `alert` 역할을 사용한다.
- 모든 버튼은 키보드 focus가 보이도록 한다.
