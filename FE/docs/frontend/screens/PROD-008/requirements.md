# PROD-008 상품 목록 요구사항

확인일: 2026-07-27

## 화면 목적

회원과 비회원이 상시 판매와 경매 예정 상품을 한 화면에서 탐색할 수 있는 상품 목록
화면을 제공한다. 이번 구현은 Jira `S15P11A108-403`의 껍데기 화면 범위로, 실제 상품
조회 API 없이 화면 구조와 기본 UI 상태를 확인하는 것을 목적으로 한다.

## 권한과 라우트

- 추천 라우트: `/products`
- 회원과 비회원 모두 접근할 수 있다.
- 인증 가드를 적용하지 않는다.

## 화면 구성

0. 상품 헤더
   - 상품 타이틀
   - 상품 탐색 목적을 설명하는 보조 문구
1. 상품 검색
   - 브랜드, 상품명, 판매자 또는 라이브 검색 입력
   - 검색 버튼
   - 홈 검색바와 같은 공통 검색 UI
   - 상품 타이틀 아래에 배치
   - 검색 시 통합 검색 결과의 상품 탭(`/search?keyword=...&type=product`)으로 이동
2. 상품 필터
   - 카테고리: 아우터, 상의, 하의, 원피스, 신발, 액세서리
   - 상태: S급(최상), A급(상), B급(중), C급(하)
   - 최소 가격, 최대 가격
   - 초기화, 적용 버튼
3. 판매 방식과 정렬
   - 전체, 즉시 구매, 경매 예정 탭
   - 총 상품 개수
   - 최신순, 가격 낮은순, 가격 높은순 정렬
4. 상품 카드
   - 4:5 상품 이미지
   - 상품 상태 등급
   - 찜 버튼
   - 브랜드, 상품명, 가격
   - 상시 판매 또는 경매 예정 배지
5. 페이지네이션
   - 이전, 1~5, 다음 버튼

## 이번 작업의 화면 상태

- mock 상품 여섯 개를 같은 타입으로 렌더링한다.
- checkbox, 판매 방식 탭, 정렬, 찜과 페이지 버튼은 로컬 화면 상태를 변경한다.
- 최소·최대 가격은 선택 입력이며 0 이상의 숫자를 입력할 수 있다.
- 최소 가격은 최대 가격보다 클 수 없고 잘못된 범위는 입력 하단에 오류로 안내한다.
- 가격 적용 시 경계값을 포함해 mock 목록을 실제로 필터링하고 결과 개수를 갱신한다.
- 가격 조건에 맞는 상품이 없으면 빈 상태와 필터 초기화 버튼을 표시한다.
- 카테고리·상태 필터와 검색은 화면 조작 확인용 안내만 제공하며 실제 목록을 다시 조회하지 않는다.
- 상품 이미지는 외부 URL 대신 저장소 내부 800×1000 WebP 실사형 자산을 사용한다.

## 접근성과 반응형

- 검색 입력은 접근 가능한 label 또는 `aria-label`과 연결한다.
- checkbox는 label 전체를 클릭할 수 있게 한다.
- 찜 버튼은 상품명과 현재 찜 상태가 포함된 `aria-label`과 `aria-pressed`를 제공한다.
- 판매 방식은 `tablist`, `tab`, `aria-selected`로 상태를 전달한다.
- 페이지 번호의 현재 위치는 `aria-current="page"`로 표시한다.
- 모든 조작 요소에 키보드 focus 표시를 유지한다.
- 1440px desktop first로 구현하고 1280px에서 3열을 유지한다. 1180px 이하에서는
  2열로 줄이고, 1024px 이하에서 필터를 상단으로 배치한다.
