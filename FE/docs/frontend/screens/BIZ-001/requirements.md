## 화면 요소

- 온보딩 기본 정보, 관심 정보, 신체 정보 완료와 회원 유형 현재 단계를 표시한다.
- 사업자 회원 이용 안내와 사업자 정보 입력 제목을 표시한다.
- 입력 정보의 이용 목적과 보호 안내를 표시한다.
- 사업자 정보 제출 버튼을 제공한다.

## 작업 경계

### S15P11A108-397

- 기본 레이아웃과 입력 UI를 구현한다.
- 입력값과 선택한 이미지 상태를 화면에서 유지한다.
- 실제 인증 API, 입력 제약, 제출 성공 이동은 구현하지 않는다.

### S15P11A108-400

- 필수값, 사업자등록번호 숫자 형식과 이미지 제약을 구현한다.
- 제출 가능 여부와 더미 제출 처리 상태를 구현한다.
- 더미 제출 성공 후 BIZ-001-2로 이동하고 HOME 이동 버튼을 제공한다.
- 실제 인증 API는 호출하지 않으며 화면 간 제출 정보는 Pinia 메모리 상태로만 유지한다.

## BIZ-001-2 인증 대기

- 경로: `/business/verification/pending`
- 제출 시각, 사업자등록번호, 상호명, 대표자명과 사업자등록증을 확인할 수 있다.
