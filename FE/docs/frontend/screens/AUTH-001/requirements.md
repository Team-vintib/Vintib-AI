# AUTH-001 이메일 회원가입

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

비회원이 이름, 이메일, 비밀번호, 약관 동의를 입력해 계정을 생성하고 온보딩으로 이동합니다.

## 추천 라우트

- `/auth/signup/email`

참고:

- `/auth/signup`은 회원가입 방식 선택 화면입니다.
- 이메일 회원가입 폼은 `/auth/signup/email`에서 제공합니다.

## 진입 경로

- 로그인 화면의 회원가입 바로가기
- 비회원 보호 기능 접근 후 가입 선택

## 핵심 구성

- 이름 입력
- 이메일 입력
- 이메일 중복 확인 버튼
- 인증코드 발송 버튼
- 인증코드 입력
- 인증코드 확인 버튼
- 비밀번호 입력
- 비밀번호 보기 버튼
- 전체 동의하기
- 필수 서비스 이용약관 동의
- 필수 개인정보 수집 및 이용 동의
- 선택 마케팅 정보 수신 동의
- 약관별 보기 버튼
- 가입하기 버튼
- 싸피어스로 가입하기 버튼
- 로그인하기 이동

## 입력 및 검증

| 항목                  | 필수 | 조건                              | 오류 처리 |
| --------------------- | ---- | --------------------------------- | --------- |
| 이름                  | 필수 | 성함 입력                         | 필드 오류 |
| 이메일                | 필수 | 이메일 형식                       | 필드 오류 |
| 이메일 중복 확인      | 필수 | 사용 가능한 이메일                | 필드 오류 |
| 인증코드              | 필수 | 숫자 6자리, 이메일 인증 완료      | 필드 오류 |
| 비밀번호              | 필수 | 8자 이상, 영문/숫자/특수문자 조합 | 필드 오류 |
| 서비스 이용약관       | 필수 | 동의 필요                         | 가입 제한 |
| 개인정보 수집 및 이용 | 필수 | 동의 필요                         | 가입 제한 |
| 마케팅 정보 수신      | 선택 | Boolean                           | 오류 없음 |

## 주요 동작

| 사용자 행동         | 처리                            | 결과                                  |
| ------------------- | ------------------------------- | ------------------------------------- |
| 중복 확인           | 이메일 형식 검증 후 중복 확인 요청 | 사용 가능 시 인증코드 발송/입력 활성화 |
| 인증코드 발송       | 중복 확인된 이메일로 코드 발송 요청 | 코드 입력 및 확인 가능                |
| 인증코드 확인       | 이메일과 6자리 코드 검증 요청    | 성공 시 회원가입용 인증 토큰 저장     |
| 가입하기            | 입력/약관 검증 후 회원가입 요청 | 성공 시 `ONBOARD-001`                 |
| 싸피어스로 가입하기 | 싸피어스 가입 화면 이동         | `AUTH-003-1`                          |
| 로그인하기          | 로그인 화면 이동                | `AUTH-002`                            |
| 전체 동의하기       | 약관 체크박스 일괄 토글         | 현재 화면                             |
| 약관 보기           | 약관 상세 표시                  | 모달 또는 별도 링크, 세부 방식 미확정 |

## 연동 데이터

- 실제 연동: `POST /api/auth/email/check-duplicate`
- 요청: `email`
- 응답: `null`
- 실제 연동: `POST /api/auth/email/send-code`
- 요청: `email`
- 응답: `null`
- 실제 연동: `POST /api/auth/email/verify-code`
- 요청: `email`, `code`
- 응답: `verificationToken`
- 실제 연동: `POST /api/auth/signup`
- 요청: `name`, `email`, `password`, `verificationToken`
- 응답: `id`, `email`, `name`, `onboardingCompleted`

## 상태 및 예외

- 입력 오류
- 필수 약관 미동의
- 중복 이메일
- 인증코드 불일치 또는 만료
- 이메일 인증 토큰 만료 또는 불일치
- 인증코드 요청 과다
- 네트워크 오류
- 처리 중 버튼 loading 및 중복 클릭 방지

## 미확정

- 약관 상세 표시 방식
- 비밀번호 정책 최종값
