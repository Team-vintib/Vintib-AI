# AUTH-001 이메일 회원가입

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

비회원이 이름, 이메일, 비밀번호, 약관 동의를 입력해 계정을 생성하고 온보딩으로 이동합니다.

## 추천 라우트

- `/auth/signup`

## 진입 경로

- 로그인 화면의 회원가입 바로가기
- 비회원 보호 기능 접근 후 가입 선택

## 핵심 구성

- 이름 입력
- 이메일 입력
- 비밀번호 입력
- 비밀번호 보기 버튼
- 전체 동의하기
- 필수 서비스 이용약관 동의
- 필수 개인정보 수집 및 이용 동의
- 선택 마케팅 정보 수신 동의
- 약관별 보기 버튼
- 가입하기 버튼
- 싸피어스로 가입하기 버튼
- 로그인하기 이동

## 입력 및 검증

| 항목 | 필수 | 조건 | 오류 처리 |
| --- | --- | --- | --- |
| 이름 | 필수 | 성함 입력 | 필드 오류 |
| 이메일 | 필수 | 이메일 형식 | 필드 오류 |
| 비밀번호 | 필수 | 8자 이상, 영문/숫자/특수문자 조합 | 필드 오류 |
| 서비스 이용약관 | 필수 | 동의 필요 | 가입 제한 |
| 개인정보 수집 및 이용 | 필수 | 동의 필요 | 가입 제한 |
| 마케팅 정보 수신 | 선택 | Boolean | 오류 없음 |

## 주요 동작

| 사용자 행동 | 처리 | 결과 |
| --- | --- | --- |
| 가입하기 | 입력/약관 검증 후 회원가입 요청 | 성공 시 `ONBOARD-001` |
| 싸피어스로 가입하기 | SSO 화면 이동 | `AUTH-003` |
| 로그인하기 | 로그인 화면 이동 | `AUTH-002` |
| 전체 동의하기 | 약관 체크박스 일괄 토글 | 현재 화면 |
| 약관 보기 | 약관 상세 표시 | 모달 또는 별도 링크, 세부 방식 미확정 |

## 연동 데이터

- 임시 후보: `POST /api/auth/signup`
- 요청 후보: `name`, `email`, `password`, `agreements`
- 응답 후보: `user`, `nextStep`

## 상태 및 예외

- 입력 오류
- 필수 약관 미동의
- 중복 이메일
- 네트워크 오류
- 처리 중 버튼 loading 및 중복 클릭 방지

## 미확정

- 이메일 인증 방식
- 약관 상세 표시 방식
- 비밀번호 정책 최종값
