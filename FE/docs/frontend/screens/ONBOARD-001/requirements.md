# ONBOARD-001 기본 정보 입력

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

회원가입 직후 사용자 기본 프로필과 주소 정보를 입력합니다.

## 추천 라우트

- `/onboarding/profile`

## 진입 경로

- 회원가입 성공 후
- SSO 인증 성공 후 온보딩 필요 상태
- 마이페이지에서 보완 진입 가능

## 핵심 구성

- 닉네임 입력
- 성별 선택
- 전화번호 입력
- 도로명 또는 지번 주소 입력/표시
- 주소 검색 버튼
- 상세 주소 입력
- 온보딩 단계 표시
- 이전 단계/다음 단계 버튼

## 입력 및 검증

| 항목 | 필수 | 조건 | 오류 처리 |
| --- | --- | --- | --- |
| 닉네임 | 확인 필요 | 특수문자 제외 2~10자 | 필드 오류 |
| 성별 | 확인 필요 | 남성 또는 여성 선택 | 선택 오류 |
| 전화번호 | 확인 필요 | 전화번호 형식 | 필드 오류 |
| 주소 | 확인 필요 | 주소 검색 결과 또는 직접 표시 | 주소 오류 |
| 상세 주소 | 확인 필요 | 동, 호수 등 상세 주소 | 필드 오류 |

## 주요 동작

| 사용자 행동 | 처리 | 결과 |
| --- | --- | --- |
| 다음 단계 | 기본 정보 저장 | `ONBOARD-002` |
| 이전 단계 | 이전 온보딩/인증 화면 이동 | 정책 미확정 |
| 주소 검색 | 주소 조회/선택 | 현재 화면 반영 |

## 연동 데이터

- 임시 후보: `PATCH /api/me/onboarding`
- 주소 후보: `GET/POST /api/addresses`

## 상태 및 예외

- 필수값 누락
- 닉네임 형식 오류
- 전화번호 형식 오류
- 주소 검색 실패
- 저장 실패

## 미확정

- 필수 필드 최종 범위
- 주소 저장 단위
- 이전 단계 이동 정책
