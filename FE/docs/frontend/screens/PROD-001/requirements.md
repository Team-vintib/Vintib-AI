# PROD-001 상품 등록 요구사항

확인일: 2026-07-30

## 화면 목적

회원이 판매할 상품의 사진, 기본 정보, 사이즈와 소재, 상태와 하자, AI 품질 검증, 가격,
판매 방식을 단계별로 입력해 상품을 등록할 수 있는 화면을 제공한다. 이번 구현은
`PROD-001~003`, Jira `S15P11A108-409`, `S15P11A108-411`, `S15P11A108-414`의 프론트 화면과
등록 흐름을 우선 완성하고, 실제 상품 등록·AI 분석·가격 추천 API 확정 전까지는 mock adapter로
성공과 실패 상태를 확인하는 것을 목적으로 한다.

## 기준 자료

- `docs/notion/기능 정의서.md`의 `PROD-001`, `PROD-002`, `PROD-003`, `PROD-009`, `PROD-010`
- `docs/notion/화면 기반 개발 요구 문서.md`의 상품 등록 및 수정 흐름과 `[PROD-001] 상품 등록 단계`
- `docs/notion/프론트엔드 디자인 구현 규칙.md`
- `.codex/plans/fe/SY009-product-registration.md`
- 가격 분포 기반 추천가 제안 참고 이미지

## 권한과 라우트

- 라우트: `/products/new`
- 로그인 회원만 접근할 수 있다.
- 비로그인 사용자는 기존 route guard 정책에 따라 로그인 화면으로 이동한다.
- 등록 완료 후 `상품 보기`는 등록된 상품 상세 화면으로 이동한다.
- `계속 등록`은 등록 draft를 초기화하고 첫 단계로 돌아간다.

## 단계 흐름

1. 사진 등록
   - 옷의 앞면 사진 1장, 뒷면 사진 1장을 필수로 업로드한다.
   - 추가 사진은 제한 없이 업로드할 수 있다.
   - 대표 이미지는 사용자가 직접 선택한다.
   - 대표 이미지를 선택하지 않으면 다음 단계로 넘어가지 않는다.
   - 앞면 사진, 뒷면 사진이 업로드되지 않으면 다음 단계로 넘어가지 않는다.
2. 기본 정보
   - 상품명, 브랜드, 색상, 카테고리, 상품 설명, 구매 시기, 구매 국가를 입력한다.
   - 상품명, 브랜드, 색상, 카테고리는 필수이지만, 상품 설명, 구매 시기, 구매 국가는 선택이다.
3. 사이즈/소재
   - 사이즈, 소재, 실측을 입력한다.
   - 소재는 선택 입력이다.
4. 상태/하자
   - 상품 상태, 하자 여부, 하자 설명은 판매자가 직접 입력한다.
   - 첫 단계에서 등록한 사진 중 AI 품질 검증에 사용할 사진을 직접 선택한다.
   - 앞면 사진 1장과 뒷면 사진 1장, 총 2장은 AI 품질 검증 대상으로 필수 선택한다.
   - 품질 검증할 사진을 선택한 후 `확인` 버튼을 누르면 선택한 각 사진에 대한 AI 품질 검사가 진행된다.
   - 품질 검사가 끝나면 사진별 결과 이미지와 설명 카드가 표시된다.
   - AI 결과는 사진별로 라벨링된 사진, 번호, 라벨별 설명으로 이뤄져있으며, < 혹은 > 버튼을 이용해 다른 사진으로 넘어갈 수 있다.
   - AI가 찾은 하자 후보는 사진 위에 빨간 네모 박스로 라벨링하고 번호를 표시한다.
   - 사진 아래에는 번호별 카드 목록을 표시한다.
   - 번호별 카드에는 AI가 자동 작성한 설명을 표시하며, 사용자는 수정할 수 없다.
   - 사용자는 각 카드에서 해당 특징이 실제 하자인지 아닌지만 선택한다. 실제 하자만 선택한다.
   - 선택한 마스킹만 사진에 빨간 네모 박스로 나오며, 선택하지 않은 마스킹은 파란 네모 박스로 나온다.
   - 품질 검증 사진별 `확인` 버튼을 누르면 사용자가 선택한 실제 하자만 반영해 박스 마스킹한 사진이 재생성되고, 사용자가 확인할 수 있다.
   - 품질 검증에 사용한 사진을 전체 다 확인 버튼이 눌려야만 다음 페이지로 넘어갈 수 있다.
   - AI 품질 검증 결과는 상품 상세 페이지의 AI 분석 결과로 노출될 수 있어야 한다.
5. 가격
   - AI 가격 추천 카드를 표시한다.
   - AI는 동일 상품 데이터를 찾아 가격대를 추천한다.
   - 가격 추천 그래프는 x축을 가격 범위, y축을 등록된 상품 수로 표현한다.
   - 막대는 가격대별 판매 상품 수를 나타낸다.
   - 빨간 세로선 마스킹으로 `S급`, `A급`, `B급`, `C급`별 추천 가격 구간을 표시한다.
   - AI 가격 추천 카드 아래에서 판매 방식과 가격을 선택한다.
   - 판매 방식은 상시 판매 또는 경매 예정 중 선택한다.
   - 상시 판매는 판매가를 입력한다.
   - 경매 예정은 시작가를 입력한다.
   - 경매 예정 상품은 경매 라이브를 선택할 수 있으며, 선택은 필수가 아니다.
6. 검토
   - 대표 이미지, 전체 이미지, 입력 정보 요약을 표시한다.
   - 단계별 수정 이동을 제공한다.
7. 완료
   - `상품 보기`는 상품 상세 페이지로 이동한다.
   - `계속 등록`은 새로운 상품 등록을 시작한다.

## 화면 구성

- 라이브 등록 화면과 유사한 단계형 UI를 사용한다.
- 상단에는 화면 제목, 등록 과정 안내, 현재 단계 진행 표시를 배치한다.
- 본문은 현재 단계 입력 영역과 보조 요약 영역을 나누어 배치한다.
- 보조 요약 영역에는 현재까지 입력한 대표 이미지, 상품명, 상태, 판매 방식 등 핵심 정보를 표시한다.
- 하단에는 취소, 임시저장, 이전, 다음, 등록 완료 액션을 배치한다.
- 사진 등록 단계는 앞면/뒷면 필수 업로드 영역과 추가 사진 영역을 구분한다.
- 상태/하자 단계는 판매자 직접 입력 영역과 AI 품질 검증 영역을 분리한다.
- AI 품질 검증 영역은 사진 선택, 검사 실행 버튼, 사진별 이동 버튼, 라벨링된 이미지,
  번호별 하자 후보 카드, 사진별 확인 버튼으로 구성한다.
- 검사 실행 버튼은 품질 검증 사진 선택 후 각 사진의 AI 품질 검사를 시작한다.
- 검사 진행이 끝나면 사진별 결과 이미지와 AI 설명 카드가 표시된다.
- AI 라벨링 이미지는 실제 하자로 선택한 마스킹을 빨간 네모 박스로, 선택하지 않은 마스킹을
  파란 네모 박스로 표시한다.
- 사진별 `확인` 버튼은 사용자가 선택한 실제 하자만 반영한 박스 마스킹 이미지를 재생성한다.
- 가격 단계는 AI 가격 추천 카드와 판매 방식/가격 입력 영역을 같은 단계 안에서 순서대로 배치한다.
- AI 가격 추천 카드는 가격 분포 막대 그래프와 상태 등급별 추천가 세로선을 표시한다.
- 검토 단계는 대표 이미지, 업로드 이미지 목록, 입력 정보, AI 검증 확인값, 가격 정보를 요약한다.
- 완료 단계는 등록 결과와 `상품 보기`, `계속 등록` CTA를 표시한다.

## 검증과 상태

- 앞면 사진과 뒷면 사진이 없으면 사진 등록 단계에서 다음 단계로 진행하지 않는다.
- 대표 이미지를 선택하지 않으면 다음 단계로 진행하지 않는다.
- 상품명, 브랜드, 색상, 카테고리, 사이즈, 실측, 상품 상태, 하자 여부, 판매 방식은 이번 구현에서 필수로 검증한다.
- 하자 있음이 선택된 경우 판매자 하자 설명을 필수로 검증한다.
- AI 품질 검증 사진은 앞면 1장과 뒷면 1장을 포함해야 한다.
- 품질 검증 사진 선택 후 검사 실행이 완료되어야 결과 확인을 진행할 수 있다.
- AI 품질 검증 후보가 있으면 사용자는 실제 하자인 후보만 선택한다.
- AI 품질 검증에 사용한 모든 사진에서 사진별 `확인` 버튼을 눌러 마스킹 이미지 재생성을 완료해야 다음 단계로 진행할 수 있다.
- AI 품질 검증 대기, 검사 중, 검사 실패, 결과 없음, 결과 있음, 사진별 마스킹 재생성 중, 사진별 확인 완료 상태를 구분한다.
- 상시 판매를 선택하면 판매가를 필수로 검증한다.
- 경매 예정 선택 시 시작가를 필수로 검증한다.
- 판매가와 시작가는 0보다 큰 숫자만 허용한다.
- 이미지 파일은 브라우저에서 미리보기 가능한 이미지 MIME만 허용한다.
- 이미지 최대 개수 제한은 두지 않는다.
- 이미지 최대 용량 기준은 미확정이므로 구현 시 FE 임시값을 표시하거나 별도 확인 후 적용한다.
- AI 가격 추천은 조회 중, 조회 실패, 추천 데이터 없음, 추천 데이터 있음 상태를 구분한다.
- 등록 실패는 mock adapter에서 확인할 수 있는 별도 상태로 제공한다.

## API 연결 범위

상품 등록 API, 이미지 업로드 방식, AI 품질 검증 API, AI 가격 추천 API, 등록 성공 응답 구조가
아직 확정되지 않았다. 이번 구현에서는 `domains/product/api/`에 mock adapter를 두고, 화면은
FE view model과 adapter 함수 경계만 바라보도록 구성한다.

실제 API 계약이 확정되면 다음 항목을 교체한다.

- 상품 생성 endpoint
- multipart 이미지 업로드 또는 선 업로드 후 상품 생성 방식
- 등록 성공 시 반환되는 상품 ID
- 이미지 업로드 실패 응답 형식
- AI 품질 검증 생성/재생성 endpoint
- AI 하자 후보의 bounding box 좌표, 라벨 번호, 설명, 실제 하자 여부 저장 형식
- AI 품질 검증 사진별 검사 상태, 확인 상태와 마스킹 재생성 결과 저장 형식
- 상품 상세에서 AI 품질 분석 결과를 조회하는 응답 형식
- AI 가격 추천 endpoint
- 가격 분포 그래프의 가격 구간, 상품 수, 등급별 추천가 응답 형식
- 경매 라이브 후보 조회 endpoint

## 접근성과 반응형

- 모든 입력은 label 또는 `aria-label`과 연결한다.
- 단계 진행 표시에는 현재 단계가 스크린 리더에 전달되도록 한다.
- 판매 방식 선택은 라디오 그룹에 준하는 키보드 조작을 제공한다.
- 대표 이미지 선택, AI 검증 사진 선택, 이미지 삭제 버튼은 버튼 이름으로 의미를 전달한다.
- AI 결과 사진 이동 버튼은 `이전 사진`, `다음 사진`처럼 현재 동작을 명확히 전달한다.
- AI 라벨 번호는 이미지 위 표시와 카드 제목에서 같은 번호로 연결한다.
- 실제 하자로 선택한 마스킹과 선택하지 않은 마스킹은 색상만으로 구분하지 않고 카드 상태나 텍스트로도 전달한다.
- AI가 자동 작성한 설명은 읽기 전용 상태임을 시각적으로도 전달한다.
- 오류 문구는 해당 입력과 연결한다.
- 1440px desktop first 기준으로 구현한다.
- 좁은 화면에서는 단계 본문과 요약 영역을 단일 컬럼으로 전환한다.
- 가격 추천 그래프는 모바일에서 가로 스크롤 또는 축약형 레이아웃을 제공한다.
- 하단 액션 버튼은 모바일에서 줄바꿈되더라도 텍스트가 겹치지 않게 한다.
