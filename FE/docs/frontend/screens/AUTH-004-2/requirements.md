# AUTH-004-2 싸피 로그인 완료 안내

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

SSAFYERS 인증 성공 후 사용자에게 가져온 이름과 이메일을 보여주고 다음 단계를 안내합니다.

## 추천 라우트

- `/auth/ssafy/success`

## 진입 경로

- `AUTH-003` 인증 성공

## 핵심 구성

- 인증 성공 안내
- 이름 표시
- 이메일 표시
- 계속하기 버튼
- 다시 인증하기 버튼
- 정보 정정 안내

## 입력 및 검증

| 항목 | 필수 | 조건 | 오류 처리 |
| --- | --- | --- | --- |
| 이름 | 확인 필요 | SSO 응답값 표시 | 정보 누락 안내 |
| 이메일 | 확인 필요 | SSO 응답값 표시 | 정보 누락 안내 |

## 주요 동작

| 사용자 행동 | 처리 | 결과 |
| --- | --- | --- |
| 계속하기 | `nextStep` 확인 | `AUTH-004`, `ONBOARD-001` 또는 홈 |
| 다시 인증하기 | SSO 재시도 | `AUTH-003` |

## 연동 데이터

- `POST /api/auth/ssafy/callback` 응답의 `linked`, `nextStep`, `user`

## 상태 및 예외

- SSO 정보 누락
- 인증 만료
- 기존 계정 연결 필요
- 온보딩 필요

## 미확정

- `싸피`와 `싸피어스` 표기 최종 통일
- 사용자 정보 수정 가능 여부
