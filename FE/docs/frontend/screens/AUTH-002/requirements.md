# AUTH-002 이메일 로그인

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

회원이 이메일과 비밀번호로 로그인하거나 싸피어스 SSO 로그인으로 이동합니다.

## 추천 라우트

- `/auth/login`

## 진입 경로

- 비회원 보호 기능 접근
- 회원가입 화면의 로그인하기
- SSO 화면의 이메일 로그인으로 돌아가기

## 핵심 구성

- 이메일 로그인 탭
- SSAFY로 로그인 탭 또는 버튼
- 이메일 입력
- 비밀번호 입력
- 로그인 상태 유지 체크박스
- 로그인 버튼
- 비밀번호 찾기
- 회원가입 바로가기
- 보안 연결 안내

## 입력 및 검증

| 항목 | 필수 | 조건 | 오류 처리 |
| --- | --- | --- | --- |
| 이메일 | 필수 | 이메일 형식 | 필드 오류 |
| 비밀번호 | 필수 | 비어 있음 불가 | 필드 오류 |
| 로그인 상태 유지 | 선택 | Boolean | 오류 없음 |

## 주요 동작

| 사용자 행동 | 처리 | 결과 |
| --- | --- | --- |
| 로그인 | 로그인 요청 | 성공 시 홈 또는 온보딩 상태 기준 이동 |
| SSAFY로 로그인 | SSO 화면 이동 | `AUTH-003` |
| 회원가입 바로가기 | 회원가입 화면 이동 | `AUTH-001` |
| 비밀번호 찾기 | 비밀번호 찾기 흐름 | 세부 화면 미확정 |

## 연동 데이터

- 임시 후보: `POST /api/auth/login`
- 요청 후보: `email`, `password`, `rememberMe`
- 응답 후보: `accessToken`, `refreshToken`, `user`

## 상태 및 예외

- 인증 실패
- 입력 오류
- 토큰 만료
- 네트워크 오류
- 처리 중 버튼 loading 및 중복 클릭 방지

## 미확정

- 로그인 후 기본 홈
- refresh token 정책
- 비밀번호 찾기 화면/정책
