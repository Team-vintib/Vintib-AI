# AUTH-004 기존 계정 연결

출처: `docs/notion/화면 기반 개발 요구 문서.md`

## 목적

SSAFYERS 인증 계정과 기존 이메일 계정 후보가 있을 때 사용자 동의 후 연결합니다.

## 추천 라우트

- `/auth/link-account`

## 진입 경로

- SSO 인증 후 기존 계정 후보가 확인된 경우

## 핵심 구성

- 이미 가입된 계정 안내
- 기존 계정 이메일 표시
- 가입 일자 표시
- 연결하기 또는 확인 버튼
- 로그인으로 이동
- 다른 이메일로 가입하기
- 닫기 또는 취소
- 인증 절차 진행 중 상태

## 입력 및 검증

| 항목 | 필수 | 조건 | 오류 처리 |
| --- | --- | --- | --- |
| 가입 계정 | 확인 필요 | 기존 계정 이메일 표시 | 계정 없음/충돌 안내 |
| 가입 일자 | 확인 필요 | 기존 계정 가입일 표시 | 정보 누락 안내 |

## 주요 동작

| 사용자 행동 | 처리 | 결과 |
| --- | --- | --- |
| 연결하기 | 계정 연결 요청 | 홈 또는 온보딩 |
| 로그인으로 이동 | 이메일 로그인 화면 이동 | `AUTH-002` |
| 다른 이메일로 가입하기 | 회원가입 화면 이동 | `AUTH-001` |
| 닫기 | 이전 안전 화면 이동 | 정책 미확정 |

## 연동 데이터

- 임시 후보: `POST /api/auth/ssafy/callback`
- 계정 연결 상태와 사용자 요약 정보

## 상태 및 예외

- 계정 확인 중
- 이미 연결된 SSO
- 연결 충돌
- 권한 없음
- 네트워크 오류

## 미확정

- 계정 연결 기준
- 실패 복구 플로우
- 닫기 버튼의 최종 이동 위치
