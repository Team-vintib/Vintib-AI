# TRYON-003/004 AI 시착 패널 요구사항

## 적용 화면

- Jira: `S15P11A108-425 [TRYON-003] [FE] AI 시착 진입 영역 구현`
- 진입 화면: `LIVE-005 /lives/:liveId`
- 기능 정의서 연관 기능: `TRYON-003 상품 가상 시착`, `TRYON-004 라이브 중 가상 시착`

## 목적

라이브 영상 맥락을 유지하면서 선택 상품과 사용자의 전신 사진으로 AI 시착을 시작하고,
생성 중·결과·실패 상태를 확인할 수 있는 패널 UI를 제공한다. 이번 구현은 mock 상태와
로컬 파일 미리보기만 제공하며 실제 사진 저장과 AI 생성 API는 연결하지 않는다.

## 진입 조건

- 라이브 상태가 `LIVE`이고 선택 상품이 있을 때 AI 시착 버튼을 활성화한다.
- 선택 상품이 없거나 방송이 예정·종료·취소 상태이면 진입 버튼을 비활성화한다.
- 패널이 열려도 영상·채팅·반응·경매 상태를 유지한다.

## 공통 패널

- 영상 영역 오른쪽에 데스크톱 기준 약 530px 폭으로 표시한다.
- 제목 `AI 시착`, 닫기 버튼과 `시착 상품 · {상품명}` 한 줄을 제공한다.
- 라이브 연결 상품 목록과 별도의 선택 상품 카드는 반복하지 않는다.
- 패널을 닫았다 열어도 진행 중인 mock 생성 또는 현재 결과를 유지한다.
- 상품 큐에서 선택 상품이 바뀌면 이전 상품의 결과·오류·저장 상태를 초기화한다.

## 상태

### 등록 사진 없음

- 큰 빈 이미지 영역에 `AI 시착에 사용할 이미지를 등록해 주세요`를 표시한다.
- `이미지 등록` 버튼과 비활성 `AI 시착 시작` 버튼을 나란히 제공한다.
- 이미지 파일을 선택하면 즉시 준비 상태로 전환한다.

### 준비

- 등록된 전신 사진 한 장을 크게 표시한다.
- `이미지 변경`과 `AI 시착 시작` 버튼을 제공한다.
- 변경한 이미지는 로컬 미리보기에만 반영하고 영구 저장 성공으로 표현하지 않는다.

### 생성 중

- 시작을 누른 시점의 전신 사진을 유지한다.
- 이미지 위에 로딩 표시와 생성 중 안내를 제공한다.
- 이미지 변경과 중복 시작을 비활성화한다.
- 가짜 진행률 숫자는 표시하지 않는다.

### 결과

- Figma의 결과 이미지 중심 구성과 사이즈·핏 안내를 유지한다.
- 결과 이미지 아래에 사이즈·핏 안내와 결과 action을 세로로 배치한다.
- 선택 상품명은 패널 헤더에서만 표시하고 결과 영역에서 반복하지 않는다.
- `다시 시착하기`, `결과 저장` 버튼을 제공한다.
- `다시 시착하기`를 누르면 즉시 재생성하지 않고 큰 등록 이미지와 이미지 변경·시작
  버튼이 있는 준비 상태로 돌아간다.
- 결과 저장은 mock 완료 피드백만 제공한다.

### 실패

- 생성 실패 안내와 `다시 시도` 버튼을 제공한다.
- 재시도하면 현재 전신 사진과 선택 상품으로 다시 생성한다.

## 파일 선택

- 브라우저 파일 선택은 한 장만 허용한다.
- MIME type이 `image/*`가 아니면 `이미지 파일만 등록할 수 있습니다` 오류를 표시한다.
- 용량·해상도 제한은 계약 미확정이므로 임의로 적용하지 않는다.
- 로컬 object URL은 교체·컴포넌트 해제 시 해제한다.

## mock 확인

| URL | 상태 |
| --- | --- |
| `/lives/101` | 등록 사진이 있는 준비 상태 |
| `/lives/101?tryon=empty` | 등록 사진 없음 |
| `/lives/101?tryon=error` | 생성 실패 후 다시 시도 |
| `/lives/101?mock=empty-products` | 선택 상품 없음, 진입 비활성 |
| `/lives/101?mock=scheduled` | 방송 예정, 진입 비활성 |
| `/lives/101?mock=ended` | 방송 종료, 진입 비활성 |

## API 경계

- 현재 등록 사진 조회·변경, 시착 지원 여부, 생성·상태 조회와 결과 저장 계약은
  `.codex/requests/be/013-live-tryon-contract.md`에서 요청한다.
- 실제 연동 전까지 query와 mock view model을 API 계약으로 사용하지 않는다.

## 제외 범위

- 실제 AI 합성·polling·WebSocket
- 실제 결과 저장·목록·삭제
- 이미지 편집·여러 이미지 선택
- 결과 비교·공유와 여러 상품 동시 시착
