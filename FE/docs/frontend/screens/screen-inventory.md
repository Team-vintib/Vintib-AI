## 라우트 제안 원칙

- 화면 ID는 문서와 추적용으로 유지합니다.
- URL은 사용자가 이해하기 쉬운 영문 명사 중심으로 제안합니다.
- 인증이 필요한 화면은 라우트 가드에서 `requiresAuth` 메타를 사용합니다.
- 미확정 이동은 구현하지 않고 `docs/frontend/decisions/open-questions.md`에 기록합니다.
