# PROD-006 상품 상세 요구사항

확인일: 2026-07-28

## 화면 목적

회원과 비회원이 상품 이미지, 판매 정보, 판매자, 연결 라이브, 판매자 고지 하자와
AI 품질 분석 결과를 확인하고 상시 판매 구매 또는 관련 기능으로 이동할 수 있는 상세 화면을
제공한다.

## 기준 자료

- Notion 기능 정의서의 `PROD-006`, `PROD-009`, `PROD-010`
- `docs/notion/화면 기반 개발 요구 문서.md`의 상품 상세 조회 흐름
- `docs/notion/프론트엔드 디자인 구현 규칙.md`
- Jira `S15P11A108-408`, `S15P11A108-410`, `S15P11A108-412`

## 권한과 라우트

- 라우트: `/products/:productId`
- 회원과 비회원 모두 접근할 수 있다.
- 찜, 구매와 AI 시착은 인증 상태에 따라 후속 작업에서 제한한다.

## 화면 구성

1. 상품 이미지
   - 대표 이미지와 썸네일
2. 구매 요약
   - 브랜드, 상품명, 가격, 판매 상태, 핵심 정보
   - 찜, AI 시착, 구매하기
3. 판매자와 연결 라이브
   - 판매자 닉네임, 팔로워 수, 판매 상품 수
   - 연결 라이브 제목, 상태, 일정
4. 상품 상세 정보
   - 설명, 브랜드, 카테고리, 색상, 소재, 사이즈, 상품 상태
   - 판매자가 직접 입력한 하자 정보
5. AI 감정
   - 상품 상세 정보 최하단의 별도 대형 영역
   - 원본 이미지와 AI 검수 이미지 좌우 비교
   - 탐지된 하자 후보와 위치 설명
   - AI 분석 한계와 비보증 안내

## AI 품질 분석 정책

- AI 결과는 상품 상세페이지에서만 표시하고 라이브 화면에는 별도로 표시하지 않는다.
- 판매자가 직접 입력한 하자 정보와 AI 탐지 결과를 구분한다.
- 등록 이미지에서 눈에 보이는 하자 후보와 위치만 안내한다.
- 상품 품질 등급, 정품·가품 판별, 숨은 하자와 품질 보증은 제공하지 않는다.
- AI 결과는 참고 정보이며 하자가 없음을 보증하지 않는다.
- `분석 전`, `분석 중`, `분석 완료`, `분석 결과 없음`, `분석 실패`를 구분한다.

## 현재 API 연결 범위

최신 Swagger의 `GET /api/products/{id}`는 상품 기본 정보 조회에 사용할 수 있다.

- 제공: 상품·판매자 ID, 판매자 닉네임, 카테고리·브랜드 ID, 제목, 설명, 상태 문자열,
  사이즈, 판매 방식·상태, 가격, 생성·수정 시각
- 미제공: 상품 이미지, 브랜드·카테고리 표시명, 찜, 판매자 통계, 연결 라이브,
  판매자 하자 목록, AI 품질 분석

미제공 필드는 mock ViewData로 구현하며, BE 계약이 추가되면
`domains/product/api/productDetailApi.ts`에서 실제 응답으로 매핑한다.
