# LIVE 라이브 목록 요구사항

확인일: 2026-07-29

## 화면 목적

회원과 비회원이 라이브 방송을 카드형 목록으로 탐색하는 공개 화면을 제공한다.
목록에서 방송을 선택하면 기존 라이브 시청 route로 이동한다.

## 기준 자료

- Jira `S15P11A108-413` 라이브 목록 카드 UI 구현
- Jira `S15P11A108-415` 라이브 목록 필터 반응 구현
- Jira `S15P11A108-418` 라이브 목록 상태 화면 구현
- `docs/notion/기능 정의서.md`의 LIVE-005
- `docs/notion/화면 기반 개발 요구 문서.md`의 라이브 카드 공통 규칙
- `docs/notion/프론트엔드 디자인 구현 규칙.md`의 16:9 라이브 카드 규칙

## 권한과 route

- 목록 route: `/lives`
- 시청 route: `/lives/:liveId`
- 목록은 회원과 비회원 모두 접근할 수 있다.
- 실제 영상, 채팅, 경매와 AI 시착은 별도 작업이다.

## S15P11A108-413 범위

- 16:9 썸네일을 사용하는 카드형 목록
- `LIVE`, `예정`, `종료` 상태 배지
- 방송 제목, 판매자, 방송 시간과 시청자 수
- 카드 선택 시 해당 `liveId`의 시청 route 이동
- desktop 3열, tablet 2열, mobile 1열 기본 grid
- 저장소 내부 WebP 이미지를 사용하는 mock 데이터
- 실제 라이브 목록 API 호출 제외

## S15P11A108-415 범위

- 기존 상품 목록과 같은 좌측 필터·우측 결과 영역 구조
- 카테고리 단일 선택 필터
- `전체`, `진행 중`, `방송 예정` 상태 탭
- 공개 목록에서 종료 방송 제외
- 경매·상시판매 등 상품 판매 방식 조건 제외
- 최신 방송순, 시청자 많은순, 제목순 정렬
- 선택 조건을 mock 목록과 결과 개수에 즉시 반영
- 같은 정렬 값에서는 `liveId`를 보조 기준으로 사용해 순서 고정
- 선택한 카테고리·상태·정렬을 각 컨트롤에 표시
- 조건과 결과 개수를 `aria-live`로 전달
- 초기화 시 전체 카테고리·전체 공개 방송·최신 방송순으로 복원
- 서버 필터링과 URL query 동기화 제외
