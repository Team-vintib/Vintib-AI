## 첫 구현 묶음

인증 화면 묶음을 먼저 구현합니다.

- AUTH-001 이메일 회원가입
- AUTH-002 이메일 로그인
- AUTH-003 싸피어스 SSO 로그인
- AUTH-004 기존 계정 연결
- AUTH-004-2 싸피 로그인 완료 안내

온보딩은 인증 직후 연결되므로 라우팅과 화면 이동 설계에는 함께 포함합니다.
