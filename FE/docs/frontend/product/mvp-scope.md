# MVP 범위

출처: `docs/notion/기능 정의서.md`

## 필수 구현

- 이메일 회원가입과 로그인
- 싸피어스 SSO 로그인과 기존 계정 연결
- 회원가입 후 온보딩
- 일반/사업자 회원 구분
- 사업자 정보 제출과 인증 상태 관리
- 상품/라이브/회원 검색
- 찜, 팔로우, 알림
- 상품 등록, 상세, 목록, 판매 방식 설정
- 예약/즉시 라이브
- 라이브 시청, 채팅, 경매, AI 시착
- 포인트 충전/조회/출금
- 배송지, 송장, 배송 조회, 구매 확정, 환불 요청
- 마이페이지 주요 관리 화면

## 필수·프로토타입

- 라이브 상시 판매 연결
- 상시 판매 구매 UI

프론트에서는 사용자 흐름과 화면 상태를 구현하되, 실제 백엔드 거래는 Swagger 확정 전까지 Mock 또는 모의 처리할 수 있습니다.

## 추가 기능

- 사업자 세금계산서 실제 발행
- 브라우저/앱 푸시 알림
- 라이브 다시보기와 상품별 타임라인
- AI 시착 결과 저장/비교/공유
- 여러 상품 조합 코디
- 상시 판매 실제 포인트 차감과 주문 생성 백엔드

## 제외 범위

- 비회원 채팅
- 이메일 알림
- 사용자 화면에 표시되는 라이브 자막
- 이미지 기반 AI 상품 설명 생성
- 별도 재고 관리 화면
- 동일 상품 다중 낙찰 경매
- 상품 수령 버튼
- 운영자 전용 페이지
- 플랫폼 판매 수수료
