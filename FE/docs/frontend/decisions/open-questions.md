# 미확정 사항

이 문서는 Codex가 임의로 판단하면 안 되는 항목을 기록합니다.

## P0: 인증 구현 전 확인 필요

| 항목 | 현재 상태 | 임시 처리 |
| --- | --- | --- |
| 비밀번호 정책 | 문서에 `8자 이상, 영문/숫자/특수문자 조합`과 `정책 미확정`이 함께 있음 | 화면 문구 기준으로 1차 검증, 서버 오류 우선 |
| 이메일 인증 방식 | 미확정 | 이메일 형식만 검증 |
| SSO 식별자와 기존 계정 연결 기준 | 미확정 | API 응답의 `nextStep` 기준 분기 |
| 로그인 후 기본 홈 | 미확정이었으나 첫 구현은 인증 | 임시로 `/` 또는 Swagger/서버 응답 기준 |
| token refresh 정책 | 미확정 | 공통 API 인스턴스에서 추후 구현 |

## P1: 온보딩/권한

| 항목 | 현재 상태 | 임시 처리 |
| --- | --- | --- |
| 주소 저장 단위와 필수 여부 | 미확정 | 필드 UI는 분리, 저장 정책은 API 기준 |
| 관심 브랜드/카테고리 선택 개수 | 미확정 | 제한 없음 또는 서버 오류 표시 |
| 신체 치수 단위/범위 | 키·몸무게 단위만 확정, 가슴·허리·엉덩이 단위와 모든 범위·소수 허용 여부 미확정 | 빈 값 또는 양의 정수만 FE 1차 검증, 임의 범위는 적용하지 않음 |
| 신체 치수 DB 컬럼 | DB 초안에는 키·몸무게만 있고 가슴·허리·엉덩이 컬럼이 없음 | BE 요청 문서에서 저장 모델과 컬럼 확정 요청 |
| 전신 사진 저장 API와 multipart 필드명 | 미확정 | `/api/me/tryon`과 `bodyPhoto` 등 FE 선행 계약 사용, Swagger 확정 시 교체 |
| 전신 사진 파일 형식/용량/해상도 | 미확정 | `image/*` 선택과 이미지 MIME type 여부만 1차 확인 |
| 전신 사진 개인정보 동의·보관 정책 | 미확정 | 안내·동의 UI와 서버 영구 저장은 구현 보류 |
| 카메라 권한 거부 감지 정책 | 미확정 | 모바일 `capture="environment"` 입력 사용, 취소 시 기존 상태 유지 |
| 일반/사업자 메뉴 차이 | 일부 미확정 | 기능 정의서 기준 |
| 본인 상품 구매/입찰/팔로우/찜 | 미확정 | 서버 응답 기준 |
