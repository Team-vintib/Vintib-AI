# 완료 조건 초안

## 공통 완료 조건

- 화면 기반 개발 요구 문서의 입력, 버튼, 상태, 이동을 반영합니다.
- 필수 입력 누락, 형식 오류, 서버 검증 오류를 화면에 표시합니다.
- API 사용 화면은 loading, success, empty, error 상태를 가집니다.
- 제출/로그인/입찰/구매 중에는 중복 클릭을 방지합니다.
- 접근 권한 오류는 `AUTH_REQUIRED` 또는 `PERMISSION_DENIED` 기준으로 처리합니다.
- 1440px desktop first 기준에서 레이아웃이 깨지지 않아야 합니다.
- 구현 후 `npm run type-check`를 통과해야 합니다.

## 인증 화면 완료 조건

- AUTH-001: 이름, 이메일, 비밀번호, 약관 동의, SSO 가입, 로그인 이동을 제공합니다.
- AUTH-002: 이메일, 비밀번호, 로그인 상태 유지, SSO 로그인, 회원가입 이동을 제공합니다.
- AUTH-003: SSO 로그인 시작, 이메일 로그인 복귀, 인증 안내를 제공합니다.
- AUTH-004-2: SSO 인증 성공 정보와 계속하기/다시 인증하기를 제공합니다.
- AUTH-004: 기존 계정 정보와 연결/로그인/다른 이메일 흐름을 제공합니다.
- 각 화면은 API 성공/실패/처리 중 상태를 표현합니다.
