# 빈티지·세컨핸드 의류 라이브 경매 플랫폼

## 1. 서비스 개요

### 1.1 서비스 소개

상품의 실제 상태와 고유한 이야기를 라이브로 확인하고, AI 품질 분석과 가격 추천을 참고하며, 가상 시착 후 실시간 경매 또는 상시 판매로 구매하는 빈티지·세컨핸드 의류 C2C 플랫폼이다.

### 1.2 서비스 배경

빈티지·세컨핸드 의류는 같은 모델이라도 사용감, 손상 상태, 희소성, 입수 과정 등 상품별 특성이 다르다. 일반적인 사진과 설명만으로는 이러한 차이를 충분히 전달하기 어렵기 때문에, 판매자가 라이브에서 상품을 직접 보여주고 특징과 이야기를 설명하도록 한다.

또한 희소 상품은 정해진 가격을 산정하기 어려운 경우가 많다. 실시간 경매를 통해 상품을 원하는 사용자들이 직접 가격 형성에 참여하도록 하여 빈티지 상품의 한정성과 가치를 살린다.

AI 가상 시착을 통해 구매 전 착용 모습을 확인하고, 여러 상품을 비교하거나 조합하는 쇼핑의 재미도 제공한다.

빈티지·세컨핸드 의류는 상품마다 얼룩, 오염, 찢어짐과 구멍 등 품질 상태가 다르지만, 판매자가 등록한 사진만으로는 하자의 위치와 정도를 쉽게 확인하기 어렵다. 이에 등록된 상품 이미지를 AI로 분석하여 눈에 보이는 하자 후보와 위치를 상품 상세페이지에서 확인할 수 있도록 한다.

또한 같은 브랜드와 모델의 상품이라도 사용감, 하자, 희소성과 거래 시점에 따라 판매 가격 차이가 크다. 판매자가 입력한 상품 정보와 AI 품질 분석 결과, 유사 상품 데이터를 함께 활용하여 상시 판매 가격과 경매 시작가 설정을 지원한다.

### 1.3 핵심 가치

| 핵심 요소 | 제공 가치 |
| --- | --- |
| 라이브 큐레이션 | 상품 상태, 소재, 실측, 사용감과 상품의 이야기를 실시간 전달 |
| 실시간 경매 | 고정 가격을 정하기 어려운 희소 상품의 가치를 입찰을 통해 형성 |
| AI 가상 시착 | 구매 전 착용 모습을 확인하고 비교·코디하는 경험 제공 |
| AI 품질 분석 | 등록 이미지에서 눈에 보이는 오염과 손상 위치를 분석하여 구매자의 상품 상태 확인 지원 |
| AI 가격 추천 | 상품 정보와 AI 품질 분석 결과를 활용하여 판매가와 경매 시작가 설정 지원 |
| 포인트 입찰 | 보유 금액 내에서만 입찰하게 하여 허위 입찰과 낙찰 이탈 방지 |
| 거래 대금 보관 | 구매 확정 전까지 판매 대금을 보관하여 거래 불이행 피해 감소 |
| 통합 거래 흐름 | 상품 등록, 라이브, 채팅, 경매, 결제, 배송과 정산을 하나의 서비스에서 처리 |

## 2. 사용자 정의

| 사용자 | 이용 범위 |
| --- | --- |
| 비회원 | 홈, 상품 목록·상세, 라이브 목록·시청, 검색 |
| 일반 회원 | 상품 구매·판매, 상품 등록, 라이브 개설, 채팅, 경매 참여, AI 시착, 팔로우, 찜, 포인트 이용 |
| 사업자 회원 | 일반 회원과 동일한 거래 기능, 사업자 인증 및 세금계산서 관련 기능 |
| 운영자 | 사업자 인증 및 운영 정책 수행. 별도 운영자 페이지는 MVP에서 제외 |

### 공통 권한 정책

- 구매자와 판매자는 별도의 계정 유형으로 구분하지 않는다.
- 모든 회원은 별도의 판매자 전환 없이 상품을 사고팔 수 있다.
- 일반 회원과 사업자 회원의 구매·판매 기능은 동일하다.
- 사업자 회원은 사업자등록번호와 사업자등록증 이미지를 제출하고 인증받아야 한다.
- 비회원은 조회만 가능하다.
- 비회원은 채팅, 찜, 팔로우, 구매, 입찰과 AI 시착을 이용할 수 없다.

| --- | --- |

### AI 품질 분석 표시 원칙

- AI 품질 분석 결과는 상품 상세페이지의 별도 영역에만 표시한다.
- 라이브 화면에는 AI 품질 분석 결과를 별도로 표시하지 않는다.
- 판매자가 직접 입력한 하자 정보와 AI가 탐지한 결과를 구분하여 제공한다.
- AI는 등록 이미지에서 눈에 보이는 하자 후보만 탐지한다.
- 품질 등급, 정품·가품 판별과 숨은 하자 보증은 제공하지 않는다.

### 가격 추천 표시 원칙

- 가격 추천은 판매자의 상품 등록·수정 화면에서만 제공한다.
- 추천 결과 아래에 핵심 추천 근거를 간단히 표시한다.
- `추천 근거 자세히 보기`를 통해 유사 상품 가격, 상품 상태와 AI 품질 분석 반영 내용을 팝업 또는 펼침 영역으로 확인할 수 있다.
- 추천값은 자동으로 판매 가격이나 경매 조건에 적용하지 않는다.
- 구매자에게는 판매자가 최종 확정한 가격만 표시한다.


# 5. 주요 서비스 흐름

## 5.1 상품 등록·AI 분석·가격 추천 흐름

```
상품 기본 정보 입력
→ 상품 이미지 등록
→ AI 품질 분석
→ 하자 후보와 위치 탐지
→ 품질 분석 결과 저장
→ 상품 정보·품질 분석 결과·유사 상품 데이터 결합
→ AI 가격 추천 및 추천 근거 제공
→ 판매자가 판매 방식 선택
→ 최종 판매 가격 또는 경매 시작가 확정
→ 상품 등록 완료
```

## 5.2 라이브 경매 판매 흐름

```
상품 등록
→ 상시 판매 또는 경매 예정 설정
→ 즉시·예약 라이브 개설
→ 등록 상품 선택
→ 라이브에서 상품 소개
→ 시작가·증액 단위·경매 시간 설정
→ 실시간 경매
→ 낙찰자 확정
→ 포인트 차감 및 거래 대금 보관
→ 판매자 송장 등록
→ 배송 완료
→ 구매 확정 또는 자동 구매 확정
→ 판매자 포인트 정산
```

## 5.3 입찰 흐름

```
다음 입찰가 버튼 선택
→ 서버 수신 순서 판정
→ 가장 빠른 요청만 입찰 성공
→ 성공자의 포인트 보류
→ 성공자는 다음 가격 단계 입찰 제한
→ 다른 사용자가 입찰 성공
→ 기존 입찰자의 포인트 보류 해제
→ 기존 입찰자 재입찰 가능
→ 종료 3초 이하 입찰 시 5초 연장
```

## 5.4 반복 질문 AI 흐름

```
판매자가 상품 설명
→ 음성을 내부 텍스트로 변환
→ 회원이 채팅으로 질문
→ 상품 정보·판매자 발언·기존 답변 검색
→ 근거가 있으면 AI 자동 답변
→ 근거가 없으면 AI 미응답
→ 판매자가 직접 답변
→ 이후 유사 질문에 답변 근거로 활용
```

(3) `MY-003`이 "경매 낙찰 주문은 AUCT 입찰 기능 구현 후 연동한다"고 남겨뒀던 것도 낡은 기록이었다 — Phase 8에서 경매 입찰·낙찰이 이미 반영돼 낙찰 주문도 같은 주문 목록 API로 조회된다. (4) `ORDER-003`(자동 구매 확정)의 "약 7일" 기준도 실제 구현(3일, `Order.markDelivered`)과 달라 바로잡았다. (5) `POINT-001`/`POINT-004`가 "결제 API 추가 선정 필요"/"최소 출금 금액 추가 논의 필요"라고 남겨뒀던 것도 이미 결정·구현된 내용(토스페이먼츠, 최소 충전·출금 10,000원, 수수료 없음)으로 갱신했다.
