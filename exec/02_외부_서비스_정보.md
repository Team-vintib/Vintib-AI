# VINTIB 외부 서비스 정보

프로젝트에서 사용하는 외부 서비스(소셜 인증, 결제, 배송 조회, 시세 조회, 자체 호스팅 인프라 등)
가입·발급·활용 정보를 정리한다. 실제 비밀키 값은 커밋하지 않으며(GitLab CI/CD Variables로
주입), 여기서는 어떤 서비스를 어떤 용도로 쓰는지 + 발급 방법만 기재한다.

| 서비스 | 용도 | 발급/가입 방법 | 관련 환경변수 | 비고 |
| --- | --- | --- | --- | --- |
| Gmail SMTP | 회원가입 이메일 인증 메일 발송 | Google 계정에서 2단계 인증 활성화 후 [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)에서 앱 비밀번호(16자리) 발급 | `MAIL_USERNAME`, `MAIL_PASSWORD` | 계정 비밀번호가 아니라 앱 비밀번호를 사용 |
| Google OAuth (로그인) | 소셜 로그인 (SSAFY SSO 대체, Authorization Code 흐름) | [Google Cloud Console](https://console.cloud.google.com/)에서 OAuth 2.0 클라이언트 ID 발급 | `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET` | 비어 있으면 구글 로그인만 실패, 나머지 로그인 수단은 정상 동작 |
| 토스페이먼츠 (결제위젯) | 포인트 충전 결제 승인 | [토스페이먼츠 개발자센터](https://developers.tosspayments.com/)에서 상점 등록, 테스트 키(`test_sk_...`/`test_ck_...`)는 사업자 등록 없이 즉시 발급 | `TOSS_SECRET_KEY`, `TOSS_CLIENT_KEY` | 폴백 없음 — 비어 있으면 포인트 충전 승인 자체가 항상 실패 |
| deliveryapi.co.kr | 택배 송장번호 기반 배송 조회 | 해당 사이트에서 API 키 발급 후, `POST /v1/webhooks/endpoints`를 수동 1회 호출해 웹훅 엔드포인트 ID를 별도로 등록 | `DELIVERY_API_KEY`, `DELIVERY_API_SECRET_KEY`, `DELIVERY_API_ENDPOINT_ID`, `DELIVERY_API_WEBHOOK_SECRET` | 비어 있으면 즉시-확정 폴백으로 동작(주문 흐름 자체는 끊기지 않음) |
| GMS (SSAFY 공용 LLM 게이트웨이) | AI 가격 책정 — 유사 상품 시세 웹검색 | SSAFY 교육 과정에서 팀에 지급되는 공용 게이트웨이 키 | `GMS_API_KEY` | 팀 공용 **유료** 쿼터, 서버사이드 웹검색은 별도 과금 — 비어 있으면 mock 백엔드로 자동 폴백. 실호출 전환은 AI팀 하드 룰에 따라 사용자가 직접 수행 |
| 네이버 오픈API (쇼핑) | AI 가격 책정 — 신상품 정가 조회 | [네이버 개발자센터](https://developers.naver.com/)에서 애플리케이션 등록 후 클라이언트 ID/Secret 발급 | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 무료지만 쿼터 있음. 비어 있으면 mock 백엔드로 폴백 |
| MinIO (S3 호환 오브젝트 스토리지) | 상품/시착 이미지 등 파일 저장 | 외부 가입 서비스 아님 — 팀에 AWS 계정이 없어(SSAFY 제공 EC2 한 대, 콘솔 없음) EC2 안에 컨테이너로 자체 호스팅. `AWS_S3_*` 자격증명 체계와 호환되도록 S3 API를 그대로 구현한 오픈소스 제품 | `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD`, `AWS_S3_*` | 자격증명은 데이터 볼륨을 처음 만들 때의 값으로 고정됨(변경 시 볼륨 삭제 필요 = 업로드 이미지 전부 소멸) |
| LiveKit (WebRTC 미디어 서버) | 라이브 방송 송출/시청 (OpenVidu v3의 미디어 코어) | 외부 SaaS 아님 — OpenVidu v3 Community 번들 전체 대신 LiveKit 미디어 코어만 EC2에 자체 호스팅(포트·리소스 절약 목적) | `OPENVIDU_API_KEY`, `OPENVIDU_API_SECRET`, `OPENVIDU_SERVER_URL`, `LIVEKIT_NODE_IP` | API key/secret은 자체 발급값(`openssl rand -base64 36`)이며 백엔드·livekit 컨테이너가 동일 값을 공유해야 함 |

## 참고

- 위 서비스 중 실제 계정 소유/발급 이력이 있는 것(GMS, deliveryapi.co.kr, 토스페이먼츠,
  Google Cloud, 네이버 개발자센터)의 **실제 발급받은 키/상점 정보**는 이 문서에 값으로
  적지 않는다 — GitLab **Settings → CI/CD → Variables**(`PROD_` 접두사)에만 등록되어 있다.
  값 확인이 필요하면 GitLab 프로젝트 설정에서 직접 조회한다.
- 세부 환경변수 목록·기본값(폴백 여부)은 `exec/01_빌드_및_배포_매뉴얼.md`, `.env.example`
  주석을 참고한다.
