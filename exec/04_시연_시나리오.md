# VINTIB 최종 발표 시연 시나리오

발표 대본(2026-08 최종 발표) 기준으로, 시연 순서에 따른 site 화면·조작(클릭 위치 등)을
상세히 정리한 문서다. 역할 구성: **발표자**(INTRO/기술설명/마무리 진행), **판매자 역할**
(상품 등록·라이브 진행), **구매자A**(상세 페이지 확인·낙찰), **구매자B**·**구매자C**(댓글·
실물 비교), **화면 전환 담당**(PPT·화면 공유 전환, 화면 확대/축소).

표의 "화면/페이지" 열은 `FE/src/router/routes.ts`에 정의된 실제 라우트 컴포넌트 기준이다.
정확한 버튼 문구·클릭 좌표는 최종 리허설에서 화면을 보며 확정한다(현재는 대본 기준 추정 —
표시된 "확인 필요" 항목은 리허설에서 실제 화면과 대조해 채운다).

| --- | --- | --- | --- |

| 3 | 화면 전환 담당 | 영상 재생 | 문제 상황을 보여주는 사전 제작 영상 재생 |

| 1-1 | 상품 등록(`ProductRegistrationPage`, `/products/new` 등 — 정확한 경로 확인 필요) 진입 | 홈 또는 마이페이지에서 "상품 등록" 버튼 클릭 → 등록 폼 진입 | "정말 아끼던 옷을 판매해 보겠다" |
| 1-2 | 상품 등록 폼 — 사진 업로드(`ProductPhotoUploader`) | 필수 항목인 **앞면·뒷면 사진**, **로고 사진** 업로드(파일 선택 또는 드래그앤드롭) | 필수 사진부터 채운다는 설명 |
| 1-3 | AI 착용컷 기능 | "AI 착용컷" 버튼 클릭 → 직접 촬영 대신 AI가 생성한 모델 착용 이미지로 대체 | 직접 촬영이 번거로움을 언급, AI 착용컷 기능 소개 |

## 9. 기술 설명 (PPT 전용, 화면 시연 없음)

발표자가 슬라이드 순서대로 진행 — 상세 스크립트는 발표 대본 원문 참고.

1. AI 가상 시착 (VLM + FLUX 파이프라인, 설문 결과 33.6%↑)
2. 상품 정보 분류 — 색상/카테고리 (FashionCLIP 파인튜닝: last-N 언프리즈 / LoRA)
3. 품질 검수 (SAM3 세그멘테이션 + 양성 판정 시스템, threshold 0.6, few-shot 텍스트 출력)
4. 시세 조회 (LLM 기반 동일 상품 식별)
5. 채팅 필터링 (Two-Track: Rule-based 1차 + 한국어 혐오표현 파인튜닝 모델 2차)
