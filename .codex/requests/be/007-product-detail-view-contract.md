# 상품 상세 화면 응답 계약 보완 요청

- **요청자 파트**: FE
- **대상 파트**: BE
- **관련 티켓**: `S15P11A108-212`, `S15P11A108-408`, `S15P11A108-410`, `S15P11A108-412`

## 배경/이유

현재 `GET /api/products/{id}`는 상품 기본 정보는 제공하지만 상품 상세 화면에 필요한 이미지,
연결 라이브, 찜, 판매자 상세, 판매자 고지 하자와 AI 품질 분석 결과는 제공하지 않는다.
`saleType`만으로는 상시 판매 상품의 라이브 연결 여부를 판단할 수 없다.

## 요청 내용

- 상품 상세 조회에서 다음 화면 정보를 함께 조회할 수 있는 계약을 요청한다.
  - 상품 이미지 목록과 대표 이미지
  - 브랜드·카테고리 표시명
  - 현재 사용자의 찜 여부
  - 판매자 팔로워 수와 판매 상품 수
  - 판매자가 직접 입력한 하자 목록
  - 현재 연결된 라이브 요약 또는 `null`
  - AI 품질 분석 상태와 분석 결과
- 연결 라이브는 BE가 상품–라이브 관계를 조회해 아래 정보를 내려주길 요청한다.
  - 라이브 ID, 제목, 상태, 시작 일시, 대표 이미지
- FE가 라이브 목록 전체를 받아 상품 ID를 직접 매칭하지 않도록 한다.
- 연결 라이브 ID가 있으면 FE는 `/lives/{liveId}` route를 구성한다.
- AI 품질 분석은 `분석 전`, `분석 중`, `분석 완료`, `분석 결과 없음`, `분석 실패` 상태를
  구분하고, 완료 시 원본 이미지·검수 이미지·하자 유형·위치·설명을 조회할 수 있어야 한다.
- 품질 등급, 정품·가품 판별과 품질 보증 값은 응답 및 화면 노출 대상에서 제외한다.

### 유사 상품 가격 분포

- 상품 상세 구매 영역에서 비슷한 상품들의 가격대를 비교할 수 있도록 특정 상품 기준
  유사 상품 목록 조회 계약을 요청한다.
- endpoint 후보는 `GET /api/products/{productId}/similar`이며 실제 path와 추천 정책은
  BE에서 확정한다.
- 화면에 필요한 최소 응답 필드는 상품 ID, 제목, 가격, 썸네일 URL, 판매 방식, 판매 상태다.
- 유사도 점수는 서버 내부 선별에 사용할 수 있지만 현재 FE 화면에는 노출하지 않는다.
- `GET /api/products` 전체 목록을 FE가 내려받아 유사 상품을 임의 판별하지 않도록 한다.
- 삭제·비공개·판매 불가 상품의 포함 여부와 최대 반환 개수는 BE 정책으로 확정한다.
