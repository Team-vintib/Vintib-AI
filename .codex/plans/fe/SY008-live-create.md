# LIVE-001/002 라이브 개설 플로우

## 배경/목표

S15P11A108-406, S15P11A108-433, S15P11A108-407 범위로 라이브 시작 화면의 개설 단계 UI, 입력 검증, 방송 테스트 더미 상태를 구현한다. 실제 라이브 생성/장비 API 계약은 아직 확정되지 않았으므로 FE 화면 상태와 mock view model 중심으로 먼저 연결한다.

## 작업 내용

- `/lives/new` placeholder를 `domains/live/pages/LiveCreatePage.vue`로 교체한다.
- 한 화면 안에서 방송 방식 선택, 방송 정보 입력, 상품 선택, 일정 또는 장비 테스트, 완료 상태를 단계별로 진행하게 구성한다.
- 예약 시작은 방송 날짜와 시작 시간 검증 후 예약 완료 상태로 이동한다.
- 즉시 시작은 카메라/마이크 더미 테스트 상태를 `대기 -> 테스트 중 -> 성공/실패`로 보여주고, 성공 시 방송 시작 가능 상태를 표시한다.
- 상품 검색과 선택은 실제 상품 API 계약 전까지 도메인 mock 데이터로 처리하고, 선택 상품 2개가 보이는 요구사항을 우선 만족시킨다.
- 검증은 기존 FE 패턴처럼 `touched`, computed error, submit guard, `aria-invalid`, `role="alert"`를 사용한다.

## 확인이 필요한 미결정 사항

- 실제 라이브 예약/즉시 생성 API의 endpoint, request/response 필드가 확정되지 않았다.
- 상품 검색 API와 선택 가능한 상품 상태 조건이 확정되지 않았다.
- 실제 카메라/마이크 권한 확인을 `navigator.mediaDevices`로 할지, 후속 WebRTC/방송 SDK에서 처리할지 확정되지 않았다.
- 문서상 사용자 유형은 일반 회원도 라이브 개설 가능하나 화면 공통 정책에는 판매자 권한 문구가 있어 권한 기준 확인이 필요하다.
