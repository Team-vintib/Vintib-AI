# 프로필 hover 로그아웃

## 배경/목표

로그인 사용자가 상단 탭 우측 프로필에 마우스를 올리면 마이페이지 관련 항목과 로그아웃 버튼을 바로 확인할 수 있게 한다. 로그아웃 버튼 클릭 시 서버 로그아웃을 시도하고 로컬 인증 세션을 정리한 뒤 비회원 홈 화면으로 이동한다.

## 작업 내용

- 기존 `GlobalNavigation.vue`의 프로필 버튼을 hover 기반 메뉴 트리거로 확장한다.
- 드롭다운에는 마이페이지 관련 이동 항목과 맨 아래 로그아웃 버튼을 배치한다.
- `domains/auth/api/authApi.ts`에 `POST /auth/logout` 호출 함수를 추가하고, 인증 스토어에 로그아웃 액션을 둔다.
- 로그아웃 진행 중에는 중복 클릭을 막기 위해 로그아웃 버튼을 비활성화한다.
- 로그아웃 완료 후 토큰과 사용자 정보를 지우고 홈(`/`)으로 이동해 `GuestHome`이 렌더링되도록 한다.

## 확인/미결 사항

- `APIs.md` 기준 로그아웃 endpoint는 `POST /api/auth/logout`이며, FE `http` baseURL이 `/api`라 코드에서는 `/auth/logout`으로 호출한다.
- 서버 로그아웃 실패 시에도 사용자 요청 관점에서는 로컬 세션을 정리해 비회원 홈으로 복귀한다.
