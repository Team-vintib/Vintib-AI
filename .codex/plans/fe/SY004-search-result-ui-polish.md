# S15P11A108-401/S15P11A108-404 검색 결과 UI 개선 계획

## 배경/목표

현재 검색 결과 화면은 기능 동작은 갖췄지만 탭의 선택 상태, 필터의 정보 구조, 상품 카드의
탐색 정보 밀도가 약하다. 이번 작업은 기존 mock 기반 검색 화면 안에서 탭, 필터, 상품 카드의
시각 구조를 개선해 쇼핑 탐색 화면처럼 보이도록 다듬는 것을 목표로 한다.

## 작업 범위

- 검색 결과 탭의 선택 상태를 더 명확하게 만든다.
  - 선택 탭은 연한 초록 배경의 칩 형태로 표현한다.
  - 숫자는 작은 배지로 분리한다.
- 필터를 큰 설정 카드가 아니라 탐색 도구처럼 정리한다.
  - 필터 헤더에 초기화 버튼을 둔다.
  - 필터 그룹은 구분선이 있는 아코디언 구조로 만든다.
  - 필터 폭은 기존 `--filter-panel-width` 기준을 유지한다.
  - desktop에서는 sticky를 적용한다.
  - 체크박스는 브랜드 컬러가 적용된 커스텀 스타일로 정리한다.
  - 선택된 필터는 결과 영역 상단에 칩으로 보여주고 개별 해제와 전체 해제를 제공한다.
- 상품 카드를 정보 중심 구조로 개선한다.
  - 카드 전체 테두리를 제거하고 이미지 영역 중심으로 구성한다.
  - 이미지 비율은 4:5, radius는 14px로 조정한다.
  - 상품 상태 배지, 찜 버튼, LIVE 배지를 이미지 위에 배치한다.
  - 브랜드, 상품명, 판매자, 가격, 경매 부가 정보를 명확히 보여준다.
  - hover 시 이미지 확대와 카드 상승 효과를 적용한다.
  - desktop 상품 그리드는 3열을 유지한다.

- 실제 경매 입찰 수/남은 시간 API 연동

## 검증 시나리오

1. 선택된 검색 탭이 칩 형태로 명확히 보인다.
2. 필터 그룹을 접고 펼칠 수 있다.
3. 필터를 선택하면 결과 영역 상단에 칩이 표시된다.
4. 필터 칩의 `x`를 누르면 해당 필터만 해제된다.
5. 전체 해제를 누르면 모든 상품 필터가 초기화된다.
6. 상품 카드에서 브랜드, 상품명, 판매자, 가격, 판매 유형 정보가 바로 보인다.
7. 경매 상품에는 입찰/남은 시간 mock 정보가 보인다.
8. 1440px에서 상품 카드가 한 줄 3개 기준으로 배치된다.
