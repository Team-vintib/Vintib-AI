# S15P11A108-260 회원 유형 선택 화면 및 상태 구현 계획

## 배경/목표

ONBOARD-004 이동 확인용 임시 화면을 일반 회원과 사업자 회원 중 하나를 선택할 수 있는
실제 화면으로 교체한다. 이번 작업은 선택 UI와 화면 상태까지만 구현하며 저장과 유형별
화면 분기는 S15P11A108-261에서 연결한다.

## 확인한 기준

- `FE/docs/notion/화면 기반 개발 요구 문서.md`는 일반 회원과 사업자 회원을 필수
  카드/라디오 선택으로 정의한다.
- 일반 회원 안내에는 상품 구매, 경매 참여와 일반 판매 활동을 포함한다.
- 사업자 회원 안내에는 상품 판매, 라이브와 사업자 기능 이용을 포함한다.
- 기능 정의서상 일반 회원과 사업자 회원의 기본 구매·판매 기능은 같으며, 사업자
  회원에게 사업자 인증·세금계산서 관련 기능이 추가된다.
- 기존 `OnboardingLayout`, `BaseButton`과 전역 디자인 토큰을 재사용한다.
- 새 라이브러리와 이미지 에셋은 추가하지 않는다.

## 작업 내용

### 회원 유형 선택 UI

- `OnboardingMemberTypeView.vue`의 임시 안내 영역을 두 개의 선택 카드로 교체한다.
- 선택 값은 `GENERAL | BUSINESS | null`로 제한한다.
- 두 카드는 하나의 라디오 그룹으로 제공해 마우스와 키보드로 선택할 수 있게 한다.
- 선택된 카드에는 테두리, 배경과 체크 표시를 함께 적용해 색상만으로 상태를 전달하지
  않는다.
- 일반 회원 카드에는 구매·경매 참여와 일반 판매 활동을, 사업자 회원 카드에는
  상품 판매·라이브와 사업자 기능을 설명한다.

### 화면 상태

- 최초 진입 상태는 아무 유형도 선택하지 않은 상태다.
- 유형을 선택하면 다른 유형의 선택은 자동 해제된다.
- 선택 전에는 다음 단계 버튼을 비활성화하고 선택 안내 문구를 제공한다.
- 선택 후에는 다음 단계 버튼을 활성화하지만 저장·이동은 261 범위로 남긴다.
- 이전 단계는 기존대로 ONBOARD-003으로 이동한다.

### 반응형·접근성

- 데스크톱에서는 두 카드를 나란히, 작은 화면에서는 한 열로 배치한다.
- 라디오 그룹에 그룹명과 안내 문구를 연결한다.
- 키보드 포커스와 선택 상태가 시각적으로 구분되게 한다.

### 문서

- `FE/docs/frontend/implementation/status.md`와
  `FE/docs/frontend/screens/screen-inventory.md`에 ONBOARD-004 선택 UI 구현 상태를
  반영한다.

## 검증 시나리오

1. `/onboarding/member-type` 진입 시 두 회원 유형 카드가 표시된다.
2. 최초에는 선택된 카드가 없고 다음 단계가 비활성화된다.
3. 카드를 선택하면 해당 카드만 선택 상태로 표시되고 다음 단계가 활성화된다.
4. 다른 카드를 선택하면 기존 선택이 해제된다.
5. 키보드로 두 선택지를 이동하고 선택할 수 있으며 포커스를 확인할 수 있다.
6. 이전 단계를 누르면 `/onboarding/try-on`으로 이동한다.
7. 1440px, 820px, 560px 이하에서 카드와 문구가 겹치거나 넘치지 않는다.
