# Member Home Personalized Sections

## 배경/목표

로그인 회원 홈 화면은 현재 플레이스홀더 상태이며, 비회원 홈 화면의 기본 콘텐츠 구성 위에 회원 전용 섹션을 추가해야 한다. `HOME-002` 팔로잉 콘텐츠와 `REC-001` 개인화 추천 요구사항에 맞춰 `내가 팔로우한 판매자`, `내 취향의 빈티지 상품` 섹션을 프로토타입 톤에 맞게 구성한다.

## 작업 내용

- `MemberHome.vue`를 비회원 홈과 동일한 홈 레이아웃 밀도와 카드 패턴을 따르는 회원 홈 화면으로 확장한다.
- 기존 `homeMockData` 기반 임시 view model을 확장해 팔로우 판매자/취향 추천 상품 데이터를 표시한다.
- API 계약이 확정되지 않은 영역은 mock view model로만 처리하고, 실제 API 연결은 후속 작업에서 adapter로 교체할 수 있게 타입을 분리한다.
- 팔로우 판매자 섹션은 판매자 프로필, 대표 이미지, 팔로우 상태, 현재/예약 라이브 또는 신규 상품 요약을 카드로 노출한다.
- 취향 추천 상품 섹션은 상품 이미지, 브랜드/판매자/카테고리, 가격, 추천 사유 태그를 포함한 상품 카드 목록으로 구성한다.
- 회원 홈 섹션 순서는 `내가 팔로우한 판매자`, `진행 중인 라이브`, `예정 라이브`, `내 취향의 빈티지 상품`, `경매 예정 상품` 순서로 구성하고 `판매 상품` 섹션은 제외한다.
- 하단 콘텐츠 band는 화면별로 한 장만 노출하고, 이미지를 고정 높이 안에 배경처럼 맞춰 프로토타입처럼 세로 길이를 줄인다.
- 검색, 라이브/상품 상세 이동, 전체보기 링크는 기존 route 상수와 경로 패턴을 사용한다.
- 반응형은 기존 홈 기준인 1440px desktop first와 768px/520px 이하 대응을 유지한다.

## 구현 목록

- [x] `homeView.types.ts`에 회원 홈 전용 seller/recommendation card 타입을 추가한다.

- [x] `MemberHome.vue`에서 검색 패널, 회원용 hero, 팔로우 판매자 섹션, 취향 추천 상품 섹션, 회원용 콘텐츠 band를 렌더링한다.
- [x] 카드/그리드/버튼 스타일을 기존 `GuestHome.vue` 스타일과 일관되게 작성하되 회원 전용 섹션의 시각적 구분을 추가한다.
- [x] 모바일에서 카드 텍스트와 버튼이 겹치지 않도록 grid column과 spacing을 조정한다.

## 확인 필요/미결정

- 프로토타입 원본이 저장소에서 확인되지 않았다. 구현 시 현재 비회원 홈 화면과 요구 문서를 기준으로 진행하고, 별도 시안 이미지나 Figma가 제공되면 세부 spacing/카드 비율을 맞춘다.
- 팔로우 판매자/개인화 추천 API 계약은 아직 확인되지 않았다. 이번 작업은 mock 데이터 기반 화면 구현으로 제한한다.
