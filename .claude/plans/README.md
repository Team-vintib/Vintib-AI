# 계획 파일 (Plans)

새 기능(신규 API/화면/도메인 로직 등)을 구현하기 전에 설계 계획을 기록하는 폴더. 관련 규율은 루트 `CLAUDE.md`의 공통 규율 참고.

## 흐름

1. 구현 전에 Plan 모드로 설계를 정리한다.
2. 계획을 이 폴더 아래, 해당 파트 하위 폴더에 md 파일로 기록한다.
3. 사용자가 계획을 검토·승인한 뒤에만 그 계획대로 코드를 작성한다.
4. 구현 중 계획과 달라지면 계획 파일도 함께 갱신한다.

버그 수정, 소규모 리팩토링처럼 설계 판단이 필요 없는 변경에는 적용하지 않는다.

## 파일 규칙

- 경로: `.claude/plans/<파트>/<번호>-<slug>.md` (파트: `be` / `fe` / `ai`, 번호는 파트별로 `001`부터 3자리로 증가)
  - 예: `.claude/plans/be/001-auction-bid-api.md`
- 계획 내용은 간결하게 작성한다. 상세 코드는 넣지 않는다.
  - **배경/목표**: 왜 필요한지, 무엇을 만드는지 1~2문장
  - **작업 내용**: 어떻게 구현할지 구두로 간단히 설명 (상세 코드 X)
  - **구현 목록**: 체크리스트(`- [ ] ...`) 형태로 작업 단위를 나열
  - (필요하면) 확인이 필요한 미결정 사항
