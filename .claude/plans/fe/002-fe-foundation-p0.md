# FE P0 기반 작업

## 배경/목표

회원가입 화면을 포함한 이후 FE 화면 개발 전에 공통으로 필요한 스타일, API, 라우팅, 레이아웃 기반을 준비한다. 작업 범위는 `FE/` 내부로 제한한다.

## 작업 내용

- Tailwind CSS를 Vite 플러그인 방식으로 연결한다.
- 디자인 문서의 색상, 간격, radius, 버튼 높이 토큰을 `src/assets/main.scss`에 선언한다.
- Axios 공통 인스턴스와 공통 API 타입을 `shared/api`, `shared/types`에 추가한다.
- 라우트 이름과 경로 상수를 `shared/constants`에 추가하고 라우터가 확장 가능한 구조를 갖도록 정리한다.
- 인증, 기본 서비스, 라이브 화면에서 사용할 기본 레이아웃 컴포넌트를 `shared/layouts`에 추가한다.
- 변경된 기반 상태를 FE 문서에 반영한다.
