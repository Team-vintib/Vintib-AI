# 파트 간 요청 문서 (Requests)

BE/FE/AI는 서로 다른 파트의 코드를 직접 수정하지 않는다. 다른 파트의 변경이 필요하면 이 폴더에 요청 문서를 남긴다. 관련 규율은 루트 `CLAUDE.md`의 공통 규율 참고.

> Claude·Codex 공통으로 이 `docs/requests/` 폴더를 쓴다. (기존 `.claude/requests/`·`.codex/requests/`는 이 폴더로 통합됨.)

## 흐름

1. 다른 파트의 코드/스펙 변경이 필요하다고 판단되면, 직접 그 파트 폴더를 수정하지 않는다.
2. 요청 내용을 이 폴더 아래, **대상 파트**의 하위 폴더에 md로 기록한다.
3. 사용자(또는 해당 파트 담당자)가 요청을 검토하고, 해당 파트에서 직접 반영한다.
4. 반영이 끝나면 요청 문서에 처리 결과를 간단히 남기거나 삭제한다.

## 파일 규칙

- 경로: `docs/requests/<대상 파트>/<번호>-<slug>.md` (대상 파트: `BE` / `FE` / `AI` 대문자, 번호는 파트별로 `001`부터 3자리로 증가)
  - 예: FE 작업 중 BE API 변경이 필요하면 → `docs/requests/BE/014-auction-bid-api.md`
- 요청 내용은 간결하게 작성한다.
  - **요청자 파트 / 대상 파트**
  - **배경/이유**: 왜 필요한지 1~2문장
  - **요청 내용**: 무엇을 바꿔달라는 것인지 구두로 간단히 설명 (상세 코드 X)
  - (필요하면) 관련 자료: API 명세, 화면, 도메인 용어 등

## 배포 규칙

- 이 `docs/requests/` 아래에 문서가 하나라도 새로 생기면(= 다른 파트에 넘길 요청이 발생하면), 해당 변경은 `main` 배포 대상으로 본다.
- 단, **실제 `main` 배포(merge/push)는 항상 사용자 승인 후 사용자가 직접 실행한다.** (직접 push 금지 규율 유지)
