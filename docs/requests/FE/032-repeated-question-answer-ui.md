# 반복질문 자동답변 — 채팅 UI에 구분 표시 필요

- **요청자 파트**: AI
- **대상 파트**: FE (경유: BE)
- **관련 티켓**: `S15P11A108-444` (chat_rag 생성기)
- **상태**: 요청 — BE가 공개 API로 감싸는 작업이 먼저 필요해서, 지금 당장 착수하실 건 아니고
  UI 설계 시 참고하시라고 미리 공유드립니다.

## 배경

라이브 방송 중 같은 질문이 반복해서 올라오면(`MIN_CLUSTER_SIZE=2`, 예: "사이즈 뭐예요?"가
2번 이상), AI가 판매자의 방송 발언(STT 전사문)을 근거로 자동 답변을 생성하는 기능을
완성했습니다. 지금은 AI 게이트웨이 내부 API(`GET /chat/lives/{id}/answers`)로만 조회
가능하고, `APIs.md`의 공개 채팅 API(CHAT-001~004)에는 아직 안 얹혀 있습니다 — 그 작업은
BE 쪽에서 해주셔야 합니다.

미리 공유드리는 이유는, 이 답변이 **일반 채팅 메시지와 같은 스트림에 섞여 나오게 될 가능성이
높아서** UI에서 어떻게 구분해 보여줄지 미리 고민해 두시면 좋을 것 같아서입니다.

## 자동답변의 특징 (UI 설계에 참고하실 내용)

- **누가 물어봤는지는 특정 안 됩니다.** "이 니트 사이즈 프리사이즈인가요?" 같은 질문 자체에
  대한 답이지, 특정 유저에게 가는 멘션/DM이 아닙니다 — 같은 질문을 한 모두에게 공통으로
  보여주면 됩니다.
- **생성까지 지연이 있습니다.** 질문이 반복 감지된 시점과 답변이 준비되는 시점 사이에
  간격(워커 처리 시간, 대략 수 초~십수 초)이 있습니다. 즉시 뜨는 게 아니라 "답변 준비 중" →
  "답변 도착" 흐름이 됩니다.
- **답변이 안 나올 수도 있습니다.** 방송 발언 중에 근거를 못 찾으면(그라운딩 실패) 조용히
  무응답 처리됩니다 — 실패 메시지나 에러를 보여줄 필요는 없고, 그냥 안 나오는 걸로 끝입니다.
- **누가 쓴 것도 아니고 판매자 발언 요약도 아닙니다.** AI가 판매자의 방송 발언을 근거로
  생성한 답변이라, "판매자가 직접 답한 것"처럼 보이면 오해 소지가 있습니다. 일반 채팅
  메시지·판매자 메시지와는 시각적으로 구분(예: 별도 배지나 색상 — "AI 자동답변" 같은 라벨)해
  주시는 걸 권장드립니다.

## 요청 내용

지금 바로 구현해 달라는 건 아니고, BE가 공개 엔드포인트를 만들면 그에 맞춰 UI 작업을
잡아주시면 됩니다. 필요하시면 그때 AI 쪽 응답 스키마(`FaqAnswer` — 질문, 답변, 근거 문서
목록, 생성 시각)를 다시 공유드리겠습니다.
