# 카테고리 분류 체계 v2 — ID 재매핑 (기존 003 문서 무효화)

**요청자 파트**: BE
**대상 파트**: AI

## 배경

카테고리 분류 내용을 개편했다(상품 등록 시 "AI가 대분류 자동 판별 → 사용자가 소분류 선택" 플로우
준비). 기존 `003-category-taxonomy-confirmed.md`가 확정했던 **1~111 ID 매핑은 이번 개편으로
전부 무효화**됐다 — 111개 → 126개로 늘었고, 51번 이후 소분류 ID는 전부 밀렸다.

## 바뀐 것

- 아우터: 베스트 제거, 패딩 추가
- 상의: 스웨트셔츠 제거, 맨투맨·민소매 추가
- 하의: 트레이닝/조거·코튼팬츠 추가, 쇼츠→숏팬츠로 개명
- 신발: 로퍼→구두, 샌들→샌들/슬리퍼로 개명
- 신규 대분류 **"원피스 및 점프슈트"**(여성·공용에만 있음, 남성은 없음 — 대분류 개수가 성별마다
  다른 첫 사례다)
- **영문 코드 컬럼(`category.name_en`)이 새로 생겨 API 응답에 포함된다.** AI가 대분류를 판별할 때
  이 영문 코드로 결과를 매핑해도 되고, 기존처럼 숫자 id로 매핑해도 된다.

## 새 ID 매핑

전체 매핑표는 `../../category-taxonomy.md` 참고(id/name/name_en/depth/parent_id 전부
정리돼 있음). 요약:

| depth | 의미 | 개수 | ID 범위 |
| :---: | --- | :---: | --- |
| 1 | 성별 | 3 | 1 ~ 3 (변경 없음) |
| 2 | 대분류 | 20 (남성 6, 여성 7, 공용 7) | 4 ~ 23 |
| 3 | 소분류 | 103 | 24 ~ 126 |

## 확인해달라는 것

- **대분류 판별 시 성별도 함께 추정해야 한다.** 대분류 이름이 성별마다 중복되고(예: "아우터"가
  남성/여성/공용 각각 다른 id), 이번엔 대분류 개수마저 성별마다 다르다(남성 6개, 여성·공용
  7개) — 성별 추정 없이는 대분류 하나를 특정할 수 없다. 라벨링 결과에 성별까지 포함해서 줄 수
  있는지 확인해달라.
- `GET /api/categories`(비회원도 조회 가능)로 전체 126개를 언제든 다시 받아볼 수 있다.
