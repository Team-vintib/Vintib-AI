# 상품 등록 카테고리 선택 입력 전환 요청

## 요청자 파트 / 대상 파트

- 요청자 파트: FE
- 대상 파트: BE

## 배경/이유

상품 등록 UX를 짧게 만들기 위해 필수 입력을 앞면/뒷면 이미지, 상품명, 품질확인, 가격으로 줄이고 카테고리는 선택 입력으로 변경하려고 합니다. 현재 BE `POST /api/products`는 `categoryId`를 `@NotNull` 및 DB `NOT NULL`로 요구해 FE에서 카테고리를 선택으로 풀면 제출 실패가 발생할 수 있습니다.

## 요청 내용

- `POST /api/products`의 `categoryId`를 선택 입력으로 변경할 수 있는지 검토해 주세요.
- 가능하다면 `ProductCreateRequest.categoryId`, `product.category_id` 저장 제약, 카테고리 미지정 상품의 목록/상세/검색/라이브 카테고리 처리 정책을 함께 정리해 주세요.
- 당장 DB 제약 변경이 어렵다면 FE가 사용할 수 있는 공식 “미분류/기타” 카테고리 ID 또는 기본 카테고리 정책을 알려 주세요.
