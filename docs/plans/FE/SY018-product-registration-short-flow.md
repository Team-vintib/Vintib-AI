# 상품 등록 초반 입력 통합

## 배경/목표

현재 `/products/new` 상품 등록은 `사진 등록 -> 기본 정보 -> 사이즈/소재 -> 상태/하자 -> 가격 -> 검토 -> 완료`의 7단계로 진행되어 초반 이탈 가능성이 크다. 사진 등록, 기본 정보, 사이즈/소재 입력을 한 화면 안에서 순차 노출해 초반 등록 흐름을 더 짧고 빠르게 느끼도록 개선한다.

## 작업 내용

- 기존 `ProductRegistrationPage`의 draft, validation, API adapter는 유지하고 화면 구성과 단계 이동 조건만 조정한다.
- 검토 단계는 제거하고 가격 단계에서 등록 제출 후 바로 완료 화면으로 이동한다.
- 첫 화면은 사진 등록 영역을 맨 위에 배치하고, 사진 등록 조건을 만족하면 같은 화면 아래에 기본 정보 입력 영역을 펼친다.
- FE 필수 입력은 앞면/뒷면 이미지, 상품명, AI 품질확인, 가격으로 축소한다. 카테고리는 BE 기본 등록 API에서 아직 필수라 `docs/requests/BE/016-product-category-optional.md`로 계약 변경을 요청한다.
- 상품명이 채워지면 같은 화면 아래에 사이즈/소재 입력 영역을 펼친다.
- 사이즈/소재까지 유효하면 다음 단계로 이동해 상태/하자, 가격, 완료 흐름을 이어간다.
- 진행 표시 문구와 사이드 요약은 새 흐름에 맞게 `사진·기본 정보·사이즈/소재`를 하나의 초반 묶음으로 보이도록 정리한다.
- 숨겨진 영역의 입력값은 초기화하지 않고, 사용자가 사진이나 기본 정보를 수정해 조건이 다시 깨지면 하위 영역만 접고 현재 draft 값은 보존한다.
- 기본 정보 단계의 색상 보조 문구는 제거하되 사용자가 직접 수정 가능한 입력 상태를 유지한다.
- 카테고리는 대분류를 제거하고 중분류/소분류 선택만 노출한다. 중분류는 향후 이미지 기반 AI 자동 입력값을 사용자가 변경할 수 있는 선택값으로 둔다.
- 이미지 업로드 영역 바로 아래, 상품명 위에 `AI 착용컷 설정` 섹션을 추가한다.
  - 상태값은 `aiModelEnabled: boolean`, `aiModelGender: 'FEMALE' | 'MALE' | null`로 draft에 둔다.
  - Front/Back 이미지가 모두 없으면 비활성화하고 안내 문구를 보여준다.
  - `사용함` 선택 시 여성/남성 중 하나를 필수로 검증하고, `사용 안 함` 전환 또는 필수 이미지 삭제 시 모델 선택값을 초기화한다.
  - 완료 단계에서 AI 착용컷 사용 여부와 모델 선택값을 요약 표시한다.

## 구현 목록

- [x] `PRODUCT_REGISTRATION_STEPS` 또는 페이지 내부 표시용 step 구성을 조정해 초반 3단계를 하나의 화면 흐름으로 통합한다.
- [x] `ProductRegistrationPage.vue`에서 사진, 기본 정보, 사이즈/소재 섹션을 같은 step template 안에 세로 배치한다.
- [x] 사진 등록 완료 여부에 따라 기본 정보 섹션 노출 조건을 연결한다.
- [x] 기본 정보 필수값 완료 여부에 따라 사이즈/소재 섹션 노출 조건을 연결한다.
- [x] 초반 통합 step의 다음 버튼은 사진, 기본 정보, 사이즈/소재가 모두 유효할 때만 활성화한다.
- [x] 기존 상태/하자, 가격, 완료 단계의 검증과 제출 동작이 깨지지 않도록 step 이동 함수를 정리한다.
- [x] 요약 패널이 통합된 초반 step 상태를 올바르게 보여주도록 조정한다.
- [x] 검토 단계를 제거하고 가격 단계에서 바로 등록 제출되도록 조정한다.
- [x] 필수 입력을 앞면/뒷면 이미지, 상품명, AI 품질확인, 가격으로 축소하고 온보딩과 같은 필수 표시를 적용한다.
- [x] 색상 보조 문구를 제거하고 카테고리 입력을 중분류/소분류 중심으로 정리한다.
- [x] 기본 정보 단계에 AI 착용컷 설정 섹션을 추가한다.
- [x] AI 착용컷 설정의 이미지 등록 상태 연동, 모델 선택 검증, 초기화 동작을 구현한다.
- [x] 완료 단계에 AI 착용컷 설정 요약을 추가한다.
- [ ] 모바일에서 세 섹션이 자연스럽게 세로로 접히고 버튼/입력 텍스트가 겹치지 않는지 확인한다.
- [x] `npm run type-check`를 실행해 타입 오류를 확인한다.

## 확인 필요 사항

- 사진 등록 완료 조건은 Front View 1장, Back View 1장으로 본다. 대표 이미지 선택은 선택 입력이다.
- 사이즈와 카테고리별 실측은 선택 입력이며, 실측을 입력한 경우에만 양수 형식을 검증한다.
- 색상과 카테고리 중분류의 AI 자동 입력은 이번 작업에서 실제 API 호출 없이 향후 연동 예정 상태만 반영한다.
- AI 착용컷 설정값은 FE draft 상태에만 저장하고, BE API 요청 필드는 기존 계약 확정 전까지 확장하기 쉬운 상태값으로 분리해 둔다.
