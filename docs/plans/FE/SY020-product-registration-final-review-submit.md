# 상품 등록 완료 단계 검토/제출 전환

## 배경/목표

현재 상품 등록 흐름에서 가격 단계 제출 후 완료 화면으로 이동하는 구조를, 완료 단계에서 입력 내용을 항목별로 검토하고 마지막 `등록하기` 버튼을 눌렀을 때 실제 등록되도록 바꾼다. 동시에 최근 추가된 상품 정보 완성도와 이미지/카테고리 UI의 정렬 문제를 정리한다.

## 작업 내용

- Front/Back 필수 이미지 업로더 내부의 제목, 필수 표시, 카운트, 설명, 버튼 정렬을 재정리한다.
- 우측 상품 정보 완성도 입력 현황은 `외 N개`로 축약하지 않고 모든 항목을 표시한다.
- 완성도 계산 대상에 기본 정보뿐 아니라 `상품 상태`, `AI 품질 검증`, 가격 관련 항목도 포함한다.
- `상품 정보를 더 채워볼까요?` 안내창은 기본 정보 단계에서 다음 단계로 넘어갈 때만 표시한다.
- 카테고리 중분류/소분류 select 영역의 라벨/헬퍼/컨트롤 줄맞춤을 정리한다.
- 가격 단계의 경매 라이브 선택 필드는 제거하고 경매 시작가만 남긴다.
- 등록 제출 시점을 가격 단계에서 완료 단계의 `등록하기` 버튼으로 이동한다.
- 가격 단계 다음에 앞에서 입력한 내용을 검증/검토하는 화면을 보여준다.
  - 이미지/기본 정보/사이즈·소재/품질/가격/AI 착용컷 등 큰 항목별 요약 표시
  - 각 큰 항목에 `정보 수정하기` 버튼 제공
  - 버튼 클릭 시 해당 단계로 이동해 수정 가능
- 검증/검토 화면에서 `등록`을 누른 뒤 API 제출 성공 시 기존 완료 결과 화면으로 전환한다.
  - 성공 후 `상품 보기` / `계속 등록` 선택 유지
- 기존 필수 검증은 유지한다. 단, 제출 전 검토 단계 이동과 실제 제출 시점이 바뀌는 영향만 최소 범위로 조정한다.

## 구현 목록

- [ ] 필수 이미지 업로더의 내부 정렬과 버튼 크기/줄바꿈 문제를 수정한다.
- [ ] 완성도 입력 현황을 전체 항목 목록으로 표시하고 축약 문구를 제거한다.
- [x] 완성도 계산 항목을 기본 정보, 상품 상태, AI 품질 검증, 가격 항목까지 확장한다.
- [ ] 완성도 안내 모달 노출 조건을 기본 정보 단계 이동 시로 제한한다.
- [ ] 카테고리 중분류/소분류 영역의 정렬을 수정한다.
- [x] 경매 라이브 선택 UI와 draft 사용부를 제거하거나 비활성 흐름에서 제외한다.
- [x] 가격 단계 다음 클릭 시 제출하지 않고 검증/검토 화면으로 이동하도록 변경한다.
- [x] 검증/검토 화면과 항목별 수정 이동 버튼을 구현한다.
- [x] 검증/검토 화면의 `등록` 버튼에서 API 제출을 실행하고, 성공 후 현재 완료 결과 화면으로 전환한다.
- [x] `npm run type-check`, `npm run lint`를 실행한다.

## 확인 필요 사항

- 완료 단계는 `검토`라는 별도 스텝을 다시 추가하지 않고, 기존 4단계의 `완료` 안에서 `검토 전/등록 완료 후` 상태를 나눠 표시한다.
- BE 요청 DTO에는 기존 필드만 전송한다. 이번 작업은 FE 흐름과 화면 구성 변경으로 제한한다.
