# 유사 상품 가격 분포

## 배경/목표

상품 상세 화면의 구매 영역 아래 여백에, 현재 상품과 비슷한 상품들이 어느 가격대에
분포하는지 확인할 수 있는 가격 분포 그래프를 추가한다. 유사도나 중간 가격은 노출하지
않고, 그래프에서 상품을 선택해 상품명과 가격을 확인한 뒤 해당 상품 상세로 이동할 수
있게 한다.

## 작업 내용

- `ProductPurchaseSummary`의 구매 버튼 아래에 기존 상품 상세 디자인 토큰과 간격 규칙을
  따르는 가격 분포 컴포넌트를 배치한다.
- 가로축은 판매 가격만 사용하고, 세로 위치는 점이 겹치지 않도록 분산하는 용도로만
  사용한다.
- 유사 상품은 가격대별 점으로 표시하고 현재 상품은 별도 테두리로 구분한다.
- 상품 점을 선택하면 상품명과 가격을 표시하며, 상세 보기 동작은 기존
  `/products/:productId` 라우트로 연결한다.
- 현재 Swagger에 유사 상품 조회 API가 없으므로 화면은 명시적인 mock view model로
  구현하고, 실제 연동에 필요한 API와 현재 Swagger 제공 범위를 별도 FE 문서로 정리한다.
- BE/AI 코드는 수정하지 않는다.

## 확인된 API 상태

- 사용 가능: `GET /api/products/{id}` 상품 상세 조회
- 사용 가능: `GET /api/products` 공개 상품 목록 조회
- 사용 가능: `POST /api/users/{userId}/wishes`, `DELETE /api/users/{userId}/wishes/{id}`
- 사용 가능: `GET /api/lives/{liveId}`, `GET /api/lives/{liveId}/products`
- 미제공: 특정 상품 기준 유사 상품 추천/가격 분포 조회
- 미제공: 상품에서 역방향으로 연결 라이브를 조회하는 계약
- 미제공: 상품 상세 응답의 찜 여부, AI 품질 분석 결과

## 미결정 사항

- 유사 상품 선별 기준과 실제 API endpoint는 BE/추천 정책 확정 전까지 mock으로 유지한다.
- `GET /api/products` 전체 목록을 FE에서 임의로 유사 상품처럼 필터링하지 않는다.
