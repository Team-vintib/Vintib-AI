# HS036 — 전신 사진 즉시 촬영 수정

## 배경/목표

온보딩과 마이페이지 전신 사진의 `즉시 촬영`이 모바일 촬영용 파일 입력만 여는 현재 동작을 개선한다. 사용자가 화면 안에서 전면 카메라 영상을 확인하고 촬영한 뒤, 결과를 다시 촬영하거나 선택할 수 있게 한다.

## 작업 내용

- `즉시 촬영`을 누르면 전면 카메라 권한을 요청하고 촬영 화면을 연다.
- 카메라 화면에서 실시간 미리보기를 제공한다.
- 촬영 후 결과 사진과 `다시 촬영`, `선택` 액션을 표시한다.
- `선택`하기 전에는 기존 전신 사진 상태를 변경하지 않는다.
- `선택`한 사진은 기존 전신 사진 미리보기 흐름에 전달한다.
- 온보딩과 마이페이지가 동일한 공통 촬영 컴포넌트와 동작을 사용한다.
- 촬영 화면은 불투명한 전체 화면 배경으로 표시해 뒤 페이지와 시각적으로 겹치지 않게 한다.
- 취소·권한 거부·카메라 없음·다른 앱의 카메라 사용 오류를 안내한다.
- 촬영 화면을 닫거나 컴포넌트가 제거되면 카메라 스트림과 임시 URL을 해제한다.
- `getUserMedia`를 지원하지 않는 환경은 전면 카메라용 파일 입력으로 대체한다.

## 구현 목록

- [x] 카메라 미리보기 화면 및 전면 카메라 연결
- [x] 촬영 결과 임시 파일·미리보기 생성
- [x] 다시 촬영·선택·취소 동작
- [x] 권한 및 장치 오류 안내
- [x] 카메라 스트림·Object URL 정리
- [x] 온보딩·마이페이지 공통 촬영 흐름 연결
- [x] 촬영 화면 불투명 배경 및 뒤 페이지 스크롤 차단
- [x] 모바일 반응형과 접근성 확인
- [x] ESLint·타입 검사·프로덕션 빌드 확인

## 확인 기준

- `즉시 촬영`을 누르면 카메라 미리보기 화면이 표시된다.
- 촬영 후 `다시 촬영`과 `선택` 중 하나를 고를 수 있다.
- `선택`한 사진이 온보딩 또는 마이페이지 전신 사진 미리보기에 표시된다.
- 촬영 화면이 열린 동안 뒤 페이지 내용이 비치거나 함께 스크롤되지 않는다.
- 촬영을 취소하면 기존 사진이 유지된다.
- 촬영 화면을 닫으면 브라우저의 카메라 사용이 종료된다.
