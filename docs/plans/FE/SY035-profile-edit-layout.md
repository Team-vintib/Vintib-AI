# 프로필 편집 버튼 동작 개선 + 레이아웃 개편

## 배경/목표

공개 프로필 화면(`ProfilePage.vue`)을 다듬는다. (1) 편집 패널을 열고 닫는 상호작용이 불명확해서
버튼 라벨로 상태를 드러낸다. (2) 현재 레이아웃(배너 위, 그 아래 아바타·닉네임·설명이 전부 세로로
쌓임)을 인스타그램 스타일(배너는 상단 전체폭 유지, 그 아래 아바타 왼쪽·정보 오른쪽 한 줄)로
재배치한다.

## 작업 내용

### 1. 편집 버튼 라벨/동작

- 패널이 닫혀 있을 때: 버튼 라벨 "프로필 편집", 클릭 시 편집 패널을 연다(현재 동작 유지).
- 패널이 열려 있을 때: 버튼 라벨이 "저장"으로 바뀐다. 클릭하면 소개글(bio)이 초안과 다를 때만
  `updateProfileBio`를 호출해 저장하고, 패널을 닫아 라벨이 다시 "프로필 편집"으로 돌아온다.
- 이미지(프로필/커버) 변경·삭제는 기존처럼 선택/클릭 즉시 반영되는 방식을 그대로 둔다("저장"
  버튼은 소개글만 커밋한다) — 이미지 API 자체가 즉시 반영형이라 별도 "임시 이미지" 상태를 두지
  않는다.
- 저장 중에는 버튼에 로딩 상태를 표시하고 중복 클릭을 막는다.

### 2. 레이아웃 재배치 (인스타그램 스타일)

- 배너(커버) 이미지는 지금처럼 상단 전체 폭을 유지한다.
- 그 아래 영역을 한 줄(가로 배치)로 바꾼다: 왼쪽에 아바타, 오른쪽에 닉네임 → 통계(상품/팔로워/
  팔로잉) → 설명 → "프로필 편집"(또는 "저장") 버튼 순서로 세로로 쌓는다.
- 다른 사람 프로필을 볼 때는 편집 버튼 자리에 지금처럼 `FollowButton`이 온다.
- 좁은 화면(모바일)에서는 기존처럼 세로 스택으로 접힌다(기존 640px 브레이크포인트 유지/조정).
- 아바타·배너 이미지가 없을 때 플레이스홀더를 만들지 않는 기존 정책(SY023)은 유지한다.

## 추가 사항 — 프로필 라이브 카드를 홈 라이브 카드 모양으로

`LiveListCard.vue`의 `variant="profile"`에 홈 `LiveCard.vue`와 같은 박스 없는 카드 모양(이미지
프레임에만 얇은 border, hover는 뜨지 않고 이미지 밝기만 변화, 4:3 비율)을 추가로 적용했다.
글씨 크기(seller/meta/viewer 확대)와 구성(뱃지 숨김, 액션 버튼 유지)은 기존 그대로 유지했다.
라이브 목록 페이지(`variant` 기본값)는 기존 박스형 카드 그대로다.
