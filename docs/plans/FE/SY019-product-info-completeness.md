# 상품 정보 완성도 패널

## 배경/목표

상품 등록 단계 진행 상태와 선택 정보 입력 충실도를 분리해서 보여준다. 선택 항목을 강제하지 않으면서도 판매자가 구매자 판단에 도움이 되는 정보를 자연스럽게 더 입력하도록 유도한다.

## 작업 내용

- 기존 상단 스테퍼는 등록 진행 단계 전용 UI로 유지한다.
- 기본 정보, 품질, 가격 단계에서만 별도의 `상품 정보 완성도` UI를 표시한다. 완료 단계에는 표시하지 않는다.
- 데스크톱에서는 상품 등록 카드 내부를 폼 영역과 우측 sticky 완성도 패널로 나눈다. 모바일/태블릿에서는 폼 상단 또는 액션 버튼 위에 세로형 카드로 배치해 가로 스크롤을 피한다.
- 완성도는 필수 항목과 분리해서 계산한다. 상품명, front/back 이미지, AI 품질 확인, 판매 가격처럼 등록을 막는 필수 항목은 완성도 추천 점수에 포함하지 않는다.
- 선택 항목 미입력은 오류로 표시하지 않고, 회색/빈 원 상태와 추천 문구로만 안내한다.
- 완성도 대상 항목은 현재 필드 구조 기준으로 다음을 사용한다.
  - 기본 정보: 상품 설명, 색상, 브랜드, 카테고리, 사이즈, 소재, 실측 정보
  - 품질: 상품 상태, 하자 정보
  - 가격: 현재 선택형 가격 보조 정보가 없어 점수 대상 없음
- 하자 이미지 전용 업로드 필드는 현재 페이지에 없으므로 별도 완성도 항목으로 추가하지 않는다. AI 품질 검증용 사진 선택은 등록 필수 검증 흐름이라 완성도 점수에서 제외한다.
- 각 추천 항목에는 중요도와 헬퍼 텍스트를 정의한다.
  - 강력 추천: 상품 설명, 카테고리, 사이즈, 실측 정보, 상품 상태, 하자 정보
  - 추천: 색상, 브랜드, 소재
- 필드 라벨 옆에 필요한 항목만 `강력 추천` 또는 `추천` 배지를 작게 표시한다. 모든 선택 필드에 `선택` 문구를 반복하지 않는다.
- 기본 정보/품질 선택 항목 섹션 상단에 선택 항목 안내 문구를 한 번 표시한다.
- 헬퍼 텍스트는 placeholder가 아니라 라벨 아래 또는 입력창 아래에 고정 표시한다.
- `추천 항목 확인` 버튼은 미입력 추천 항목 중 중요도가 높은 항목으로 이동한다.
  - 현재 단계에 있으면 해당 필드/섹션으로 scroll 및 focus 처리
  - 다른 단계에 있으면 step 이동 후 렌더링 완료 시 scroll 및 focus 처리
  - 버튼/선택 카드처럼 input focus가 어려운 항목은 섹션 wrapper에 `tabindex="-1"`을 주고 focus 처리

## 확인 필요 사항

- 완성도 점수는 선택 정보 입력 유도용이며 등록 가능 여부와 무관하다.
- 현재 BE 요청 필수값 중 카테고리는 FE에서 선택 처리되어 있으나, BE 계약 변경 요청은 기존 `docs/requests/BE/016-product-category-optional.md`에 남아 있다.
- 가격 단계에는 별도 선택형 가격 보조 필드가 없어 완성도 항목을 추가하지 않는다.
