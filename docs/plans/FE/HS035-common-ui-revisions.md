# HS035 — 공통 UI 수정

## 배경/목표

사용자 피드백을 기준으로 전 화면의 상단 소개 영역을 정리하고, 한글 단어가 어색하게 끊기는 문제를 줄인다. 온보딩·상품 등록·라이브 등록의 단계 표시 디자인도 온보딩 기준으로 통일한다.

## 작업 내용

- 기존 다크 배경(`#0A0A0A`)은 유지한다.
- 상품·라이브 목록을 포함한 주요 화면의 고정 페이지 제목과 홍보성 설명을 제거한다.
  - 검색 결과명, 프로필 섹션명, 인증·입력 단계 제목 등 기능에 필요한 제목은 유지한다.
  - 보이는 제목을 제거한 화면은 `aria-label`로 화면 목적을 유지한다.
- 전역 한글 줄바꿈 규칙을 추가하고, 단계 표시 라벨이 말줄임표로 잘리지 않게 조정한다.
- 상품 등록과 라이브 등록 단계 표시를 온보딩의 마커·연결선·완료 상태 디자인에 맞춘다.
- 등록 단계 표시가 좁은 화면에서 세로 한 줄로 무너지지 않도록 단계 열을 유지한다.

- [x] 주요 화면의 고정 페이지 제목·소개 설명 제거
- [x] 한글 단어 단위 줄바꿈과 긴 문자열 예외 처리
- [x] 상품 등록 단계 표시를 온보딩 디자인으로 통일
- [x] 라이브 등록 단계 표시를 온보딩 디자인으로 통일
- [x] 수정 파일 ESLint 및 Vite 모듈 변환 확인
- [ ] 전체 타입 검사 (`node_modules`의 Toss Payments SDK 미설치로 중단, `package.json`에는 의존성 선언됨)

## 확인 기준

- 모든 기본·인증·온보딩·라이브 레이아웃은 기존 `#0A0A0A` 배경을 유지한다.
- 상품/라이브 목록 등의 상단에 고정 제목과 소개 문구가 보이지 않는다.
- 긴 한글 문구는 단어 중간에서 우선 끊기지 않고, 공간이 부족할 때만 안전하게 줄바꿈된다.
- 상품 등록과 라이브 등록의 단계 표시가 온보딩과 같은 시각 규칙을 사용한다.
