# HS032 — AI 시착 다중 선택 입어보기 (카테고리당 1개, TRYON-005)

- Jira: `S15P11A108-545` [TRYON-005 | FE] (개인 AI 시착 페이지) / 에픽 `S15P11A108-210` [TRYON]
- 브랜치: `feat/210-tryon-selective-save` (HS031 위에 이어서)

## 배경/목표

`TryOnComposer`는 현재 `selectedProductId` **단일 선택**이라 옷 하나만 입어본다.
사용자 요청: **AI 시착 페이지에서만 여러 옷을 동시에 선택**해 함께 입어보되, **카테고리당 1개**
(상의 1·하의 1 …). 상품 상세/라이브 시착 팝업(단일 시착)은 그대로 둔다.

결과 방식은 **(A) 선택한 옷마다 결과 1장씩** 생성(승인). 각 결과는 HS031의 선택 저장 UX대로
개별 미리보기 후 맘에 드는 것만 저장한다.

## 작업 내용

1. 선택 상태를 배열(`selectedProductIds`)로 변경.
   - 옷 클릭: 이미 선택됐으면 해제(토글), 아니면 추가.
   - **같은 카테고리(`categoryName`)로 이미 고른 옷이 있으면 교체**(카테고리당 1개). `categoryName`이
     없으면 교체하지 않는다(각각 허용).
2. 카드 다중 하이라이트(`selectedProductIds.includes`), `입어보기`에 선택 개수 표시.
   활성 조건: 전신사진 + 1개 이상 선택.
3. `tryOn()`: 선택한 옷마다 mock 결과 1장 생성 → `generatedResults`(배열, 각 `saved` 플래그).
4. 결과 미리보기 스트립: 결과 카드(이미지 + 상품명 + [저장]/저장됨). 카드별 저장 시 `emit('generated')`.
   "다시 입어보기"로 전체 미리보기 폐기(저장 안 함).
