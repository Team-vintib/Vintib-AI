# HS034 — 온보딩 관심 카테고리 성별 제거·대분류 그룹 선택 (ONBOARD)

- Jira: `S15P11A108-560` [ONBOARD-001/ONBOARD-002 | FE] 성별 선택 제거 및 관심 중분류 선택 / 에픽 60 [ONBOARD]
- 브랜치: `feat/60-onboarding-interest-midcategory` (develop-FE 기준)

## 배경/목표

온보딩 관심 선택이 카테고리 택소노미를 `depth <= 2`로 노출해 **성별(depth 1: 남/여/공용) + 성별별
대분류(depth 2)**가 섞여 나왔다. 대분류는 성별마다 중복된다(남 상의=5, 여 상의=11, 공용 상의=18).

사용자 요구: 성별 구분을 없애고 **대분류(상의/하의/아우터/신발/가방/액세서리/원피스)만** 이름별 1개로
보여주고, 하나 선택하면 **그 이름의 모든 성별 id가 함께 선택**되게 한다. 기본정보 단계의 성별
입력은 그대로 둔다(A안) — 저장 payload/BE 계약 영향 없음.

## 작업 내용 (`OnboardingInterestsView.vue`만)

- 카테고리 로딩: `depth === 2`만 필터 → **이름으로 묶어** `{ label, ids[] }` 그룹으로 만든다.
- 선택 상태: `selectedCategoryIds`(flat)는 유지(API 계약 그대로). 그룹 토글 시 그 그룹의 모든 id를 함께 넣거나 뺀다.
- "N개 선택"은 선택된 **그룹 수** 기준으로 표시.
- 마크업: 체크박스(label) → 버튼 토글로 변경.
