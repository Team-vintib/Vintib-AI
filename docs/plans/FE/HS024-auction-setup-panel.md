# AUCT-001/002 판매자 경매 설정 패널

## 배경/목표

435에서 자리만 잡아둔 판매자 방송 화면의 **경매 설정 slot**에 실제 판매자 경매 패널을 넣는다.
판매자는 현재 선택(소개) 상품에 대해 **시작가·증액 단위·진행 시간을 설정(AUCT-001)**하고
**경매를 시작(AUCT-002)**한다. 진행 중에는 현재가·최고 입찰자·남은 시간을 모니터링하고,
종료 시 낙찰/미낙찰 상태를 본다. 실제 입찰·서버 판정·실시간 이벤트는 계약이 없어 **로컬 mock**까지만.

Jira 436 `[AUCT-003~006 | FE] 경매 설정 패널 UI 구현` (스토리 `-97`/`-98`, 에픽 `-209`[AUCT]).

## 기준 자료

- 기능 정의서 §4.7 — 판매자: **AUCT-001**(조건 설정), **AUCT-002**(단일 상품 시작),
  **AUCT-011**(최고 입찰자 표시), **AUCT-010**(종료 직전 자동 연장), **AUCT-014**(미낙찰 복원)
- 시청자 입찰 패널 `LiveAuctionPanel.vue` / `liveAuction.types.ts` (표현 일관성용, 재사용 아님)
- `docs/requests/BE/005-auction-chat-contract.md`(경매 시작/입찰/종료 이벤트 요청 중),
  `docs/requests/FE/001`(경매 토픽 Phase 6~8 ⏳)

## 작업 내용

### 패널 상태 (판매자 관점)

- **IDLE(설정 전)** — 시작가 / 증액 단위 / 진행 시간 입력 + 유효성 + **경매 시작** 버튼.
  - 입력 방식: **프리셋 버튼 + 직접 입력 둘 다**(사용자 결정 #3).
    - 진행 시간 프리셋: 1분 / 3분 / 5분 (직접 입력 가능)
    - 증액 단위 프리셋: 1,000 / 5,000 / 10,000P (직접 입력 가능)
    - 시작가: 직접 입력(선택 상품 가격 있으면 mock 기본값)
  - 프리셋/기본값·범위는 계약 미확정 → **mock(BE 확인 필요)**.
  - 현재 소개 상품이 없거나, 방송 중(`LIVE`)이 아니거나, 값이 유효하지 않으면 시작 비활성.
- **RUNNING(진행 중)** — 현재가 · 최고 입찰자(AUCT-011) · 남은 시간 표시.
  - 종료 3초 이하 유효 입찰 시 자동 연장 표시(AUCT-010)는 mock 연출.
  - 판매자는 입찰하지 않는다(모니터링). mock 타이머로 진행.
- **ENDED_WON(낙찰)** — 낙찰자 닉네임 · 낙찰가.
- **ENDED_FAILED(미낙찰, AUCT-014)** — 입찰자 없음 → 상품을 판매자 관리로 되돌린다는 안내 +
  **"판매 방식 선택(PROD-005)" 링크/버튼만 배치(placeholder).**
  실제 PROD-005 화면·동작은 **내일 별도 작업** → 이 패널에선 자리+링크만, 동작은 준비 중 처리.

### 배치

- `LiveBroadcastPage`의 경매 설정 slot(435 placeholder)을 이 패널로 교체.
- 현재 **선택 상품** 기준으로 설정/진행. 선택 상품 없으면 안내 문구.
- 판매자가 상품을 전환(437)하면 경매 대상도 그 상품으로 바뀌는 흐름 고려.

### 컴포넌트 경계

- `domains/auction`에 **판매자 경매 패널 신규** — 시청자 입찰 패널과 분리.
  - `components/SellerAuctionPanel.vue`, `types/sellerAuction.types.ts`,
    `constants/sellerAuctionMockData.ts` (이름은 구현 시 확정)
- 시청자 `LiveAuctionPanel.vue`는 그대로 두고 재사용/수정하지 않는다.

### API / mock 경계

- AUCT-001/002 **설정·시작 트리거 엔드포인트**, 진행 중 실시간(현재가/최고입찰자/자동연장),
  종료 판정 — 계약 없음 → **mock**. 계약에 없는 값은 `Mock 전용`으로 명시.
- `009`에 경매 시작/입찰/종료 **이벤트(브로드캐스트)** 요청이 있으나, 판매자의 **설정·시작 트리거
  (REST)**는 별도다 → 구현 중 필요하면 `docs/requests/BE/`에 추가/보강(중복 요청 금지).
