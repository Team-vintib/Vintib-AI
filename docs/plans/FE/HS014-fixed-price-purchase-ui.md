# SALE-001 상시 판매 구매 UI

## 배경/목표

스토리 `S15P11A108-212`의 상시 판매 상품 상세·구매 진입 화면을 구현한다.
`S15P11A108-408`, `S15P11A108-410`, `S15P11A108-412`를 순서대로 완료하며,
Notion 기능 정의서의 `PROD-006`, `PROD-009`, `PROD-010`에 추가된 AI 품질 분석 영역을
상품 상세 정보 최하단에 포함한다.

## 작업 내용

- `PROD-006` 상품 상세 route의 placeholder를 실제 상세 View로 교체한다.
- 상품 이미지, 판매 상태, 상품 정보, 가격, 판매자, 연결 라이브와 구매 진입 영역을 구성한다.
- 구매하기 영역과 연결 라이브 영역 아래, 상품 상세 정보의 가장 마지막에 큰 `AI 감정` 영역을 둔다.
- AI 감정 영역은 원본 이미지와 AI 검수 이미지를 좌우로 비교하고, 이미지 아래에 분석 설명과
  참고 안내를 표시한다.
- Figma의 기존 하자 영역을 `AI 분석`으로 교체하고 내부 제목은 `AI 분석 설명`으로 표시한다.
- 상세 화면 CSS는 기존 FE 디자인 토큰과 공통 radius/hover/focus 규칙을 따른다.
- 상세 화면 타이포는 섹션 26/36/700, 카드 17/24/600, 본문 15/24/400,
  캡션 13/18/400, 배지 12/16/600 규칙을 따른다.
- 검수 이미지의 탐지 위치는 굵은 빨간 네모와 큰 숫자 마커로 표시한다.
- 썸네일 선택, 찜, 판매자·라이브 이동, AI 시착, 구매하기 등 화면 반응을 mock 상태로 연결한다.
- 로딩, 조회 실패, 상품 없음, 판매 완료와 AI 분석 상태를 구분해 표시한다.
- 실제 상세·구매 API가 확정되기 전까지 화면 전용 타입과 mock adapter를 사용한다.
- 상품 이미지는 실제 상품 사진처럼 생성한 프로젝트 로컬 PNG 자산을 사용한다.
- AI 검수 이미지는 같은 원본 사진 위에 하자 위치만 표시한 별도 mock 이미지를 사용한다.
- Figma `PROD-006`의 세로 썸네일·대표 이미지·우측 구매 정보 배치를 그대로 따른다.

## AI 품질 분석 표시 원칙

- AI 결과는 상품 상세페이지의 별도 영역에만 표시한다.
- 판매자가 직접 입력한 하자 정보와 AI가 탐지한 결과를 구분한다.
- 등록 이미지에서 눈에 보이는 하자 후보와 위치만 안내한다.
- 품질 등급, 정품·가품 판별, 숨은 하자 탐지와 품질 보증 표현은 제공하지 않는다.
- AI 결과가 참고 정보이며 하자가 없음을 보증하지 않는다는 안내를 표시한다.
- 상태는 `분석 전`, `분석 중`, `분석 완료`, `분석 결과 없음`, `분석 실패`로 구분한다.

## 우선순위 및 Jira 단위

### 1. S15P11A108-408 — 상품 상세 상단 UI 구현

- 상품 상세 페이지 골격과 공통 내비게이션을 배치한다.
- 대표 이미지·썸네일, 판매 상태, 상품명, 가격과 핵심 상품 정보를 배치한다.
- 판매자 정보, 연결 라이브, 구매·AI 시착 CTA의 정적 UI를 구성한다.
- 상세 정보 최하단에 큰 AI 감정 영역의 정적 골격을 추가한다.
- AI 감정 골격에는 `원본 이미지 | AI 검수 이미지` 2열 비교와 하단 설명 영역을 포함한다.
- 상세 route parameter와 화면용 mock 데이터를 연결한다.

### 2. S15P11A108-410 — 상품 상세 옵션 반응 구현

- 썸네일 선택에 따라 대표 이미지를 변경한다.
- 찜 상태와 접근 가능한 버튼 상태를 반영한다.
- 판매자 프로필, 연결 라이브, AI 시착, 구매하기를 현재 존재하는 route 또는 안내 상태에 연결한다.
- 판매 방식과 판매 상태에 따라 가격·CTA·안내 문구를 변경한다.
- AI 감정 대상 이미지 선택 시 원본 이미지와 대응하는 검수 이미지를 함께 변경한다.
- 비교 이미지에는 각각 `원본 이미지`, `AI 검수 이미지` 레이블과 대체 텍스트를 제공한다.
- 좁은 화면에서는 비교 이미지를 세로로 배치하되 설명 영역의 순서를 유지한다.

### 3. S15P11A108-412 — 상품 상세 상태 화면 구현

- 상세 로딩, 오류·재시도, 상품 없음, 판매 완료 상태를 구현한다.
- AI 감정의 `분석 전`, `분석 중`, `분석 완료`, `분석 결과 없음`, `분석 실패` 상태를 구현한다.
- 분석 완료 상태에서 검수 이미지와 하자 유형·위치 설명을 표시한다.
- 분석 결과 없음 상태에서 눈에 띄는 하자 후보를 찾지 못했다는 문구와 비보증 안내를 표시한다.
- 분석 실패 상태에서 이미지 문제 또는 시스템 오류 안내를 표시한다.
- 판매자 입력 하자와 AI 감정 결과를 시각적·문구상으로 명확히 구분한다.
- 색상 외 텍스트와 아이콘으로도 상태를 구분하고 키보드 focus를 확인한다.

## 확인이 필요한 사항

- `구매하기` 이후 이번 스토리에서 구현할 범위는 별도 구매 확인 화면 구현 전에 다시 확인한다.
- 판매자 프로필·라이브 상세·AI 시착의 미구현 route는 임의 생성하지 않고 기존 route 범위에서만 연결한다.

## 후속 TRYON 작업 메모

- 상품 상세의 `AI 시착`은 `TRYON-003 상품 가상 시착` 화면으로 연결한다.
- 라이브 화면의 `AI 시착`은 `TRYON-004 라이브 중 가상 시착` 사이드바로 연결한다.
- 전신 사진·상품 이미지 합성 요청과 결과 타입은 두 화면에서 공통으로 재사용한다.
- `TRYON-003`은 결과 이미지 중심의 별도 화면, `TRYON-004`는 라이브 영상·음성을 유지하는
  사이드바 형태로 각 Figma 배치를 따른다.
