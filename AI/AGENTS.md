# VinTib AI Codex 작업 규칙

담당 범위·기술 스택·실행 방법은 `README.md` 참고. 이 문서에는 Codex가 지켜야 할 규율만 적는다.
루트 `AGENTS.md`의 공통 규율(새 기능 계획 선승인, 파트 간 요청 문서, push 금지 등)은 이 폴더 작업에도 그대로 적용된다.

AI 파트는 아직 별도 코드 컨벤션 문서(`CLAUDE.md`)가 없다. 정해지는 대로 이 문서와 함께 갱신한다.

## 새 기능 계획

신규 AI 기능(가상 시착 합성, 상품 설명 초안 생성, 라이브 발언 기반 정보 추출 등)은 바로 구현하지 않는다. 먼저 계획을 세워 `.codex/plans/ai/`(루트 기준)에 md로 기록하고, 사용자 승인 후 그 계획대로 구현한다. 파일 규칙(경로, `<이니셜><번호>-slug.md` 형식, 계획 내용 구성)은 루트 `.claude/plans/README.md`를 그대로 따르되 저장 위치만 `.codex/plans/ai/`를 쓴다. 버그 수정 등 설계 판단이 필요 없는 변경에는 적용하지 않는다.

## 다른 파트 코드 수정 금지

BE/FE 코드는 직접 수정하지 않는다. BE나 FE 쪽 변경이 필요하면 `.codex/requests/be/` 또는 `.codex/requests/fe/`(루트 기준)에 md로 요청 문서를 남긴다. 형식은 루트 `.claude/requests/README.md`를 그대로 따르되 저장 위치만 `.codex/requests/<대상 파트>/`를 쓴다.
