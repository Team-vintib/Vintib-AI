# 품질 검수 — 모델 입력 전처리 방법론

`S15P11A108-307`

SAM3 세그멘터(`worker/models/sam3/`)가 이미지를 판정하기 전/후에 적용하는 전처리·필터 기법을
요약한다. 상세 설계는 `.claude/plans/ai/CH006-sam3-quality-segmenter.md` 참고.

## 1. 의류 세그먼트(시맨틱 세그멘테이션) + 마스킹 크롭

- **무엇**: `"clothing"` 프롬프트로 SAM3에 옷 위치를 먼저 물어 마스크+bbox를 얻고, 그 bbox로
  이미지를 자른 뒤 마스크 밖(배경) 픽셀을 검정(0)으로 채운다. 하자 탐지는 이 마스킹된
  이미지 안에서만 수행한다.
- **왜**: 배경(바닥·소품 등)이 하자로 오탐되는 걸 프롬프트 튜닝이 아니라 **입력 자체를
  제한**해 구조적으로 막는다.
- **안전장치**: 의류를 못 찾으면 크롭·마스킹 없이 원본 그대로 탐지한다 — "하자 없음"과
  "의류 탐지 실패"를 뭉개지 않기 위해서다.
- **코드**: `worker/models/sam3/segmenter.py`의 `_detect_garment()`/`_crop_and_mask_to_garment()`

## 2. 의류 겹침 필터 (사후 안전망)

- **무엇**: 위 마스킹을 거쳤어도 크롭 여백·마스크 경계 반올림 때문에 일부 하자 인스턴스가
  여전히 의류 밖에 걸칠 수 있다. 원본 좌표로 되돌린 뒤 실제 의류 마스크와 겹침 비율을 한 번 더
  확인해, 기준(현재 60%) 미만이면 버린다.
- **왜**: 1번 전처리의 잔여 오차를 잡는 2차 방어선.
- **안전장치**: 의류 마스크 자체가 없으면(1번이 실패) 이 필터도 통째로 건너뛴다(위와 같은
  이유).
- **코드**: `worker/models/sam3/findings.py`의 `filter_by_garment()`

## 3. 양성(benign) 판정/억제

- **무엇**: 하자 프롬프트와 별개로 "정상" 프롬프트(암홀/넥라인/밑단/소매끝 = 구조적,
  주름/접힘/그림자/솔기/프린트 = 질감형)도 같은 이미지에서 탐지해 두고, 하자 인스턴스가 이
  양성 인스턴스에 겹치면 억제(제거) 후보로 본다.
- **왜**: SAM3가 "구멍"을 찾는 프롬프트를 실제 손상과 옷이 원래 가진 개구부(넥라인 등)를
  구분하지 못해서 생기는 오탐(LAB-46 실측)에 대한 대응.
- **핵심 분기**: 구조적 개구부는 **겹치기만 하면 confidence 상관없이 무조건 억제**(실제
  손상이 정확히 그 구조물과 같은 모양·위치일 수 없다는 전제). 질감형은 **양성 쪽
  confidence가 하자보다 높을 때만** 억제(솔기 근처 실밥 뜯김처럼 진짜 하자가 그 위에 생길
  수 있어서, 무조건 지우면 안 된다).
- **코드**: `worker/models/sam3/findings.py`의 `suppress_benign()`,
  프롬프트 정의는 `worker/models/sam3/prompts.py`의 `STRUCTURAL_BENIGN_PROMPTS`/
  `TEXTURE_BENIGN_PROMPTS`

## 4. 인스턴스 면적 기반 노이즈·과포화 필터링

- **무엇**: 인스턴스 면적 비율이 너무 작으면(`min_area_ratio` 미만) 노이즈로 폐기하고, 반대로
  너무 크면(`max_defect_area_ratio` 초과) "하자"가 아니라 세그멘테이션 자체의 실패로 보고
  폐기한다.
- **왜**: 옷 전체를 하자로 잡는 것 같은 극단적 오탐을 걸러낸다.
- **코드**: `worker/models/sam3/segmenter.py`의 `_instances_from()`

## 구현 현황

위 4가지 전처리·필터 방법론은 전부 `worker/models/sam3/`에 구현·배선까지 끝난 상태다
(`run_inference()`에서 순서대로 호출됨. mock/실모델 양쪽 백엔드로 스모크 테스트 완료).

`S15P11A108-307` 설명에 있는 두 항목 중 **"모델 입력 전처리 적용"은 완료**, **"RoboFlow 활용
데이터 라벨링 후 테스트"는 아직 미착수**다 — 라벨링된 검증셋이 없어 위 임계치(`score_threshold`/
`garment_overlap_min`/`benign_containment` 등)가 전부 육안 판단 기반 미확정 값으로 남아 있다
(`worker/models/sam3/registry.py` 주석 참고).
