# TRYON 알파 테스트 — 데이터 수집 포맷

CatVTON 가상 시착 파이프라인 고도화(에픽 `S15P11A108-210`)를 위해 팀원들에게 모델/의류
이미지를 받아 직접 테스트해보고 평가받는 알파 테스트 진행을 위한 데이터 수집 포맷이다.
Notion 데이터베이스에 아래 속성으로 표를 만들어 수집한다.

## 배경

- 외부 사용자가 아니라 팀원(내부 인력)이 실제 데이터로 파이프라인을 써보고 피드백을 주는
  단계라 **알파 테스트**로 분류한다(외부 일부 사용자 대상이면 베타 테스트로 구분).
- CatVTON은 모델 사진 1장 + 의류 사진(상의/하의/모자/신발, 각각 선택)을 입력으로 받는
  구조라, 수집 포맷도 이 입력 구조를 그대로 반영한다.

## Notion 데이터베이스 속성

한 행 = 한 명의 제출 건. 제출 → 결과 → 평가를 같은 행에서 이어서 채운다.

| 속성명 | 타입 | 설명 |
| --- | --- | --- |
| 제출자 | 사람(Person) | 누가 제출했는지 |
| 제출일 | 날짜 | 자동 기록 |
| 모델 이미지 | 파일과 미디어 | 정면 전신, 배경 단순한 곳에서 촬영 (필수) |
| 상의 이미지 | 파일과 미디어 | 옷만 평평하게 펴서 촬영 (선택) |
| 하의 이미지 | 파일과 미디어 | 위와 동일 (선택) |
| 모자 이미지 | 파일과 미디어 | 위와 동일 (선택) |
| 신발 이미지 | 파일과 미디어 | 위와 동일 (선택) |
| 테스트 조합 | 텍스트 | 예: "상의+모자만", "전체 조합" — 어떤 부위를 합성해보고 싶은지 |
| 비고 | 텍스트 | 원단 특징(광택/패턴 등), 조명 등 참고할 점 (선택) |
| 합성 결과 | 파일과 미디어 | AI팀이 결과 업로드 (테스트 후 채움) |
| 평가 점수 | 선택(Select) | 1~5 또는 "나쁨/보통/좋음/매우 좋음" |
| 평가 코멘트 | 텍스트 | 어색한 부분, 잘 된 부분 등 (테스트 후 채움) |

## 촬영 가이드 (제출자 안내용)

- 의류 사진은 실측 기능 카메라 가이드와 마찬가지로, 배경과 대비되는 곳에서 옷을 평평하게
  펴서 촬영한다 — 대비가 약하면 배경 제거 품질이 떨어진다.
- 모델 사진은 정면 전신, 단순한 배경에서 촬영한다.
- 모자/신발은 각각 단독으로 촬영한다(신은 상태·쓴 상태 촬영 아님).
